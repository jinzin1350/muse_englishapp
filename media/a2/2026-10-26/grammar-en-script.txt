Tutor: Hello! Today we learn conditionals.
Tutor: The zero conditional talks about things that are always true.
Tutor: If you heat ice, it melts.
Tutor: We use if plus present simple in both parts.
Tutor: If you mix red and white, you get pink.
Tutor: The first conditional talks about a real future possibility.
Tutor: If it rains tomorrow, we will stay at home.
Tutor: We use if plus present simple, and will plus verb.
Tutor: Never use will in the if part.
Tutor: Say if it rains, not if it will rain.
Tutor: Unless means if not.
Tutor: Unless you hurry, you will miss the bus.
Tutor: A common mistake is to use would after if for the future.
Tutor: Say if you study, you will pass, not you would pass.
