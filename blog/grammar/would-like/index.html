I'd Like and Would You Like...?

Level: A1 · Free grammar guide

We use I'd like (= I would like) to ask for things politely: I'd like a coffee, please.

We use Would you like…? to offer something or to invite someone: Would you like some tea? Would you like to come to my party?

Form

+ noun+ to + verb
RequestI'd like a sandwich, please.I'd like to book a table, please.
Offer / invitationWould you like a drink?Would you like to come with us?
QuestionWhat would you like?Where would you like to go?

I'd like is the same for all people: I'd like, you'd like, she'd like, we'd like, they'd like (no -s).

After would like, use to + verb: I'd like to go (not I'd like go or I'd like going).

How to answer

  • Offers: Would you like a biscuit? – Yes, please. / No, thank you.
  • Invitations: Would you like to come to the cinema? – Yes, I'd love to! / I'm sorry, I can't.

Do you like or would you like?

Do you like coffee? = in general, always. Yes, I drink it every day.

Would you like a coffee? = an offer, now. Yes, please.

I'd like is more polite than I want. In a shop or café, say: I'd like a hot chocolate, please.

Examples

  1. I'd like a glass of water, please. (request + noun)
  2. We'd like to see the menu, please. (request + to + verb)
  3. Would you like some cake? – Yes, please. (offer)
  4. Would you like to have dinner with us? – I'd love to. (invitation)
  5. What would you like to drink? (question)
  6. She'd like to learn Spanish. (wish)
  7. Would you like a bag? – No, thank you. (polite answer)
  8. I'd like a room for two nights, please. (at a hotel)
  9. Where would you like to sit? (question + to + verb)
  10. Do you like tea? – Yes, I drink it every morning. (in general (not would))

Common mistakes

❌ I'd like go home.

✅ I'd like to go home. (Would like + to + verb.)

❌ She'd likes a coffee.

✅ She'd like a coffee. (No -s after would.)

❌ Do you like a drink? (offering now)

✅ Would you like a drink? (For offers, use would you like.)

❌ Would you like a biscuit? – Yes, I like.

✅ Yes, please. (Answer an offer with Yes, please / No, thank you.)

❌ I would like to a pizza.

✅ I would like a pizza. (Before a noun, no to.)

❌ Would you like coming with us?

✅ Would you like to come with us? (Would like + to + verb, not -ing.)
