Be Able To (vs Can and Could)

Level: B1 · Free grammar guide

Be able to means the same as can: I can swim = I am able to swim.

We need it because can has only two forms (can and could). For other tenses and structures, we use be able to: I'll be able to help you tomorrow.

Forms of be able to

FormExample
future: will be able toYou'll be able to speak English fluently soon.
present perfect: have been able toI haven't been able to sleep well recently.
infinitive: to be able toI'd love to be able to play the guitar.
-ing: being able toBeing able to drive is very useful.
after modals: might / must / should be able toHe might be able to help you.

Never put two modals together: I will be able to drive (not I will can drive).

Could or was able to?

For a general ability in the past, use could or was able to: When I was young, I could run very fast.

For one specific situation where someone succeeded, use was / were able to (or managed to), not could: The fire spread quickly, but everyone was able to escape.

In the negative, both are fine: I couldn't / wasn't able to finish the test.

With verbs of the senses and thinking, could is normal even for one situation: I could see the sea from my room. I could understand everything.

Examples

  1. I'll be able to help you after lunch. (future)
  2. She hasn't been able to find a job yet. (present perfect)
  3. I hope to be able to visit you next summer. (infinitive)
  4. I love being able to work from home. (-ing)
  5. You must be able to speak French for this job. (after must)
  6. After three hours, we were able to fix the car. (one success)
  7. The museum was closed, so we weren't able to see the paintings. (negative)
  8. When she was five, she could read. (general past ability)
  9. Are you able to come on Friday? (present question)
  10. If you practise, you'll be able to play this song in a week. (first conditional)

Common mistakes

❌ I will can come tomorrow.

✅ I will be able to come tomorrow. (Don't use two modals together.)

❌ I haven't could finish it.

✅ I haven't been able to finish it. (Can has no present perfect: use been able to.)

❌ He might can help.

✅ He might be able to help. (After a modal, use be able to.)

❌ We could catch the last train last night. (one success)

✅ We were able to catch the last train. (One specific success: was / were able to.)

❌ Can drive is useful.

✅ Being able to drive is useful. (-ing form: being able to.)

❌ I'd like can speak Japanese.

✅ I'd like to be able to speak Japanese. (Infinitive: to be able to.)
