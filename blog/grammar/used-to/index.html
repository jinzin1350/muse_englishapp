Used To

Level: B1 · Free grammar guide

We use used to + base verb for past habits and past states that are not true now: I used to play football every weekend. (I don't now.) She used to live in Paris. (She doesn't live there now.)

Used to only talks about the past. There is no present form.

How to form used to

FormExample
Positivesubject + used to + base verbWe used to go camping every summer.
Negativesubject + didn't use to + base verbI didn't use to like vegetables.
QuestionDid + subject + use to + base verb?Did you use to have long hair?
Short answersYes, + subject + did. / No, + subject + didn't.Yes, I did. / No, I didn't.

After did and didn't, write use to (no d): didn't use to, Did you use to…? You will also see didn't used to in informal writing, but didn't use to is the standard form.

Used to sounds like yoos-ta. The d is not pronounced.

When do we use used to?

  • Past habits (repeated actions): I used to take the bus to school.
  • Past states: There used to be a cinema here. He used to be very shy.

We don't normally use used to for one action, or to say how many times or how long something happened. Use the past simple: I went to Rome in 2019. I lived there for ten years.

For present habits, use the present simple, often with usually: I usually walk to work. (not I use to walk to work)

Used to or would?

For past habits, you can also use would: Every summer, we would go to the lake. But don't use would for past states: I used to have a dog. (not I would have a dog)

Used to, be used to and get used to

FormMeaningExample
used to + base verba past habit or stateI used to work at night.
be used to + -ing / nounit's normal for me; I'm familiar with itI'm used to working at night.
get used to + -ing / nounit's becoming normal for meI'm getting used to the cold weather.

After be used to and get used to, use -ing or a noun, not the base verb: I'm used to getting up early. (not used to get up)

Examples

  1. I used to walk to school when I was a child. (past habit)
  2. There used to be a bakery on this street. (past state)
  3. My dad didn't use to cook, but now he loves it. (negative)
  4. Did you use to play an instrument? (question)
  5. She used to have blonde hair. (past state)
  6. They didn't use to have a car. (negative)
  7. What did people use to do before smartphones? (wh- question)
  8. On Sundays, my grandmother would make pancakes for everyone. (would for a past habit)
  9. I'm a teacher now, but I used to work in a shop. (not true now)
  10. I'm not used to driving on the right. (be used to + -ing)

Common mistakes

❌ I use to play tennis when I was young.

✅ I used to play tennis when I was young. (In positive sentences, write used (with d).)

❌ I used to playing football.

✅ I used to play football. (Used to + base verb.)

❌ Did you used to live here?

✅ Did you use to live here? (After did, write use to.)

❌ I use to get up at 7 every day.

✅ I usually get up at 7 every day. (Used to has no present form. Use the present simple.)

❌ I would have a dog when I was young.

✅ I used to have a dog when I was young. (Would is for past actions, not states.)

❌ I used to go to Paris last year.

✅ I went to Paris last year. (One finished action: use the past simple.)

❌ I'm not used to get up early.

✅ I'm not used to getting up early. (Be used to + -ing.)

Exercises (16)

Choose the correct answer.

1. I ___ swim every day when I lived near the sea.
A past habit: used to + base verb.
2. ___ you use to have a pet?
Questions: Did + subject + use to + base verb.
3. There ___ a cinema in our town, but it closed.
A past state: used to be.
4. When I was a child, we ___ go to the beach every Sunday.
Would + base verb can describe a past habit (an action that was repeated).
5. My grandparents ___ in a small village.
A past state: used to + base verb.
6. I ___ have long hair when I was at school.
Having long hair is a state, so use used to, not would.
7. I've lived in Canada for years, so I ___ the cold.
It's normal for me = be used to + noun.
8. She ___ like coffee, but now she drinks it every day.
Negative: didn't use to + base verb.
9. It took me months to ___ driving on the left.
It's becoming normal = get used to + -ing.
10. He ___ to Japan once, in 2015.
One finished action: past simple, went.
11. What did people ___ do before the internet?
After did, write use to.
12. Choose the correct sentence about now.
For present habits, use the present simple: I usually walk to work.
13. Which sentence is correct?
Be used to + -ing: I'm not used to working.
14. We ___ a car when I was little, so we walked everywhere.
Negative past state: didn't use to + base verb.
15. Did you use to ___ to school?
Use to + base verb.
16. There ___ any shops near my house, but now there are three.
A negative past state: didn't use to be. Would isn't used for states.
