Mixed Conditionals

Level: B2 · Free grammar guide

Mixed conditionals combine two different times. Both the condition and the result are imagined, but one is in the past and the other is in the present.

If I had taken that job, I would be rich now. (past condition → present result) If I were taller, I would have joined the basketball team. (present condition → past result)

Past condition, present result

if + past perfect, would + base verb, often with now: If you had listened to me, you wouldn't be in this mess now. (You didn't listen, so you're in a mess now.)

Present condition, past result

if + past simple, would have + past participle: If I spoke French, I would have understood the film. (I don't speak French, so I didn't understand the film.)

The present condition is usually a general fact or a permanent situation: If she weren't so shy, she would have asked him. If I were is more formal; If I was is common in speech.

Comparing the conditionals

Could and might also work in the result: If he had trained harder, he might be a professional now.

Examples

  1. If I had studied medicine, I would be a doctor now. (past → present)
  2. If she hadn't missed the flight, she would be in Rome now. (past → present)
  3. If we had bought that house, we would live by the sea. (past → present)
  4. If I weren't afraid of heights, I would have gone on the roller coaster. (present → past)
  5. If he were more organised, he wouldn't have forgotten the meeting. (present → past)
  6. If you had told me earlier, I wouldn't be so worried now. (past → present)
  7. If they had left on time, they would be here by now. (past → present)
  8. If I spoke better English, I would have passed the interview. (present → past)
  9. If it hadn't rained so much last night, the roads wouldn't be flooded now. (past → present)
  10. If he had trained harder, he might be a professional now. (might in the result)

Common mistakes

❌ If I had taken the job, I would have been rich now.

✅ If I had taken the job, I would be rich now. (A present result (now): would + base verb.)

❌ If I would have studied, I would be a doctor.

✅ If I had studied, I would be a doctor. (Don't use would in the if clause.)

❌ If I am taller, I would have joined the team.

✅ If I were taller, I would have joined the team. (An imagined present condition: past simple (were/was).)

❌ If she hadn't missed the bus, she will be here now.

✅ If she hadn't missed the bus, she would be here now. (Imagined result: would, not will.)

❌ If he had trained harder, he would being a professional now.

✅ If he had trained harder, he would be a professional now. (Would + base verb.)

❌ If I spoke French, I would understood the film.

✅ If I spoke French, I would have understood the film. (A past result: would have + past participle.)

Exercises (16)

Choose the correct answer.

1. If I had taken that job, I ___ rich now.
Past condition, present result (now): would be.
2. If she ___ the train, she would be here now.
The condition is in the past: hadn't missed (past perfect).
3. If I spoke Japanese, I ___ the film last night.
Present condition, past result (last night): would have understood.
4. If he ___ so lazy, he would have finished the project on time.
A present fact about him (he is lazy): weren't (or wasn't).
5. If we had left earlier, we ___ there by now.
Past condition, present result (by now): would be.
6. Choose the mixed conditional.
Past condition (I'd saved) + present result (I'd have a car now).
7. If I ___ afraid of flying, I would have visited you in Australia.
A present fact (I'm afraid of flying): weren't.
8. If you had gone to bed earlier, you ___ so tired now.
Present result (now): wouldn't be.
9. If she had accepted his offer, she ___ in Paris now.
Past condition, present result: would live.
10. If I ___ a car, I would have driven you to the airport yesterday.
A present fact (I don't have a car): past simple, had.
11. If he had trained harder, he ___ a professional player now.
A possible present result: might be.
12. If I weren't so busy, I ___ to your party last weekend.
Present condition, past result (last weekend): would have come.
13. Which sentence means: I didn't save money, so I don't have a house now?
Past condition (I'd saved) + present result (I'd have a house now).
14. If they ___ the instructions, the machine wouldn't be broken now.
The condition is in the past: had read.
15. If I were you, I ___ that email yesterday.
If I were you (present) + a past result (yesterday): wouldn't have sent.
16. If it hadn't rained all night, the roads ___ flooded now.
Past condition, present result (now): wouldn't be.
