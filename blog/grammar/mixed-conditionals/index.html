Mixed Conditionals

B2 · C1

Mixed conditionals combine two different times. The condition is in one time and the result is in another: If I had taken that job (past), I would be rich now (present).

They're built from the second and third conditionals. If you need to review those first, see Second Conditional and Third Conditional.

B2 · Upper-intermediate

Past condition, present result B2

if-clause (past perfect)main clause (would + base verb)
If I had saved more money,I would be able to buy a house now.
If you hadn't eaten so much,you wouldn't feel sick now.
If we had taken the earlier train,we'd be there by now.

  • If I hadn't missed the bus, I would be at work now. (past → present)
  • If she had accepted the offer, she would live in Dubai today. (past → present)
  • If you had listened to me, we wouldn't be lost. (past → present)
  • If they hadn't moved away, we'd still be neighbours. (past → present)

Common mistakes:

  • ❌ If I learned to drive last year, I would have a car now. → ✅ If I had learned to drive last year, I would have a car now. (Past condition: past perfect.)
  • ❌ If you had gone to bed earlier, you wouldn't have been tired now. → ✅ If you had gone to bed earlier, you wouldn't be tired now. (Present result: would + base verb.)

Present condition, past result B2

if-clause (past simple)main clause (would have + past participle)
If I were taller,I would have joined the basketball team.
If she didn't love him,she wouldn't have married him.
If I spoke Spanish,I would have understood the guide yesterday.

  • If I weren't so shy, I would have spoken to her. (permanent → past)
  • If he knew the area, he wouldn't have got lost. (general fact → past)
  • If you were more organised, you wouldn't have forgotten the meeting. (a habit → past)
  • If we didn't have kids, we would have gone on the trip. (present situation → past)

Common mistakes:

  • ❌ If I was braver, I would ask her out last week. → ✅ If I was braver, I would have asked her out last week. (Past result: would have + past participle.)

Practice: B2

1. If I had booked the tickets earlier, we ___ in the front row now.
Past condition, present result: would be sitting.
2. If she hadn't broken her leg, she ___ in the race today.
Result now: would be running.
3. If you had taken the medicine, you ___ (feel) better now.
Present result: would feel.
4. If I ___ afraid of flying, I would have visited you last summer.
A permanent situation: If I weren't afraid…
5. If she spoke better English, she ___ the interview last week.
Past result: would have passed.
6. He's a careless person. If he ___ (be) more careful, he wouldn't have broken his phone last week.
A permanent quality: were / was (mixed); had been (third conditional) is also correct.

C1 · Advanced

Mixed conditionals with continuous forms and modals C1

  • If we hadn't missed the flight, we would be lying on a beach right now. (continuous result)
  • If I'd brought my laptop, I could work on the train. (could = would be able to)
  • If you weren't working tonight, we would have invited you. (continuous condition)
  • If she hadn't been so rude, he might still be her friend. (might = perhaps would)

Common mistakes:

  • ❌ If I hadn't lost my keys, I could have been inside now. → ✅ If I hadn't lost my keys, I could be inside now. (Present result: could + base verb.)

Choosing the right conditional C1

ConditionResultFormExample
real, now / futurerealif + present, willIf it rains, we'll stay in.

imaginary, pastpastif + past perfect, would haveIf I'd had time, I'd have helped.
imaginary, pastnowif + past perfect, wouldIf I'd taken the job, I'd be rich.
imaginary, always / nowpastif + past, would haveIf I were braver, I'd have said something.

  • If I had a car, I'd drive. (imaginary now)
  • If I'd had a car, I'd have driven. (imaginary past)
  • If I'd bought a car, I'd drive to work now. (past → now)
  • If I didn't hate driving, I'd have driven. (always → past)

Common mistakes:

  • ❌ If I didn't miss the train this morning, I would be at work now. → ✅ If I hadn't missed the train this morning, I would be at work now. (A past event in the if clause: past perfect.)

Practice: C1

7. If I hadn't broken my phone, I ___ you the photos now.
Present result: could + base verb.
8. If it ___, we would have had the barbecue in the garden.
The rain is in progress now: weren't raining.
9. If we hadn't sold the car, we ___ (could / drive) to the beach tomorrow.
Present result: could drive.
10. I'm not a confident person. If I ___ more confident, I would have applied for the manager's job last month.
A permanent quality now, past result: If I were…
11. I didn't go to the doctor last week, and now I feel terrible. If I had gone, I ___ better now.
Past condition, present result.
12. We didn't buy the tickets last month, and now they're sold out. If we had bought them, we ___ (go) to the concert tonight.
Past condition, result tonight: would be going.
