So, Such, So...That and Such...That

Level: B2 · Free grammar guide

So and such make an adjective or noun stronger: It's so cold! It's such a cold day!

With that, they show a result: It was so cold that we stayed inside. So that shows a purpose: I left early so that I wouldn't miss the bus.

So or such?

UseFormExample
so+ adjective / adverbThe film was so boring. She speaks so quickly.
such a / an+ (adjective) + singular countable nounIt was such a boring film.
such+ (adjective) + plural or uncountable nounThey're such kind people. It was such bad weather.
so many / few+ plural nounThere were so many people.
so much / little+ uncountable nounI've got so much work.
such a lot of+ plural or uncountable nounThere's such a lot of traffic.

In formal English, you may see so + adjective + a + noun: It was so difficult a question that nobody could answer. (= such a difficult question)

Result: so / such… that

The coffee was so hot that I couldn't drink it. It was such a long journey that we stopped twice. In speech, that is often left out: I was so tired I fell asleep.

Purpose: so that

So that + subject + verb (often can, could, will, would) shows why someone does something: Speak louder so that everyone can hear you. I wrote it down so that I wouldn't forget.

Compare: to + verb has the same meaning when the subject is the same: I left early to catch the bus. See Infinitive of Purpose.

Examples

  1. I'm so happy for you! (so + adjective)
  2. You're such a good friend. (such a + adjective + noun)
  3. They have such beautiful children. (such + plural noun)
  4. There was so much noise that I couldn't sleep. (so much + uncountable)
  5. We had such a lot of fun at the party. (such a lot of)
  6. The test was so easy that everyone passed. (result)
  7. It was such an interesting book that I read it twice. (result)
  8. There were so few tickets left that we couldn't sit together. (so few)
  9. I'm saving money so that I can travel next year. (purpose)
  10. She spoke quietly so that she wouldn't wake the baby. (purpose, past)

Common mistakes

❌ It was so a nice day.

✅ It was such a nice day. (Such a + adjective + noun.)

❌ She's such kind.

✅ She's so kind. (So + adjective (no noun).)

❌ It was such a bad weather.

✅ It was such bad weather. (Weather is uncountable: no a.)

❌ There were such many people.

✅ There were so many people. (So many + plural noun.)

❌ The film was very boring that I left.

✅ The film was so boring that I left. (For a result, use so… that, not very… that.)

❌ I wrote it down so that not forget it.

✅ I wrote it down so that I wouldn't forget it. (So that + subject + verb.)

Exercises (16)

Choose the correct answer.

1. The film was ___ boring that I fell asleep.
Adjective, no noun: so boring that…
2. It was ___ day that we went to the beach.
Singular noun: such a nice day.
3. There were ___ people at the concert that we couldn't move.
Plural noun: so many people.
4. They're ___ kind people. I really like them.
Adjective + plural noun: such kind people.
5. I've got ___ homework that I can't go out tonight.
Uncountable noun: so much homework.
6. She speaks ___ quickly that I can't understand her.
Adverb: so quickly.
7. We had ___ time at the party!
Singular noun: such a great time.
8. I'll write it down ___ I don't forget it.
Purpose + subject + verb: so that.
9. It was ___ expensive restaurant that we only had a salad.
Singular noun starting with a vowel sound: such an expensive restaurant.
10. There was ___ little time that we had to take a taxi.
so little + uncountable noun.
11. He's ___ a good teacher that all his students pass.
such a + adjective + noun.
12. Choose the correct sentence.
Adjective, no noun: so bad that. (Weather is uncountable, so not such a bad weather.)
13. Speak louder ___ everyone can hear you.
Purpose + subject + can: so that.
14. I've never seen ___ beautiful sunset.
Singular noun: such a beautiful sunset.
15. There's ___ a lot of traffic today. Let's walk.
Fixed phrase: such a lot of.
16. It was ___ difficult a question that nobody could answer it.
Formal pattern: so + adjective + a + noun.
