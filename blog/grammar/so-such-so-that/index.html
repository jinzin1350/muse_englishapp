So, Such and So That

B1 · B2 · C1

So and such make a description stronger: I'm so tired! It was such a long day! Add a that-clause to show the result: It was so cold that we stayed inside.

Don't confuse them with so that, which shows purpose: I left early so that I could catch the train.

B1 · Intermediate

So or such? So hot, such a hot day B1

sosuch
so + adjective: It's so cold!such a / an + adjective + singular noun: It's such a cold day!
so + adverb: She speaks so fast.such + adjective + plural noun: such nice people
so much / so many + noun: so many peoplesuch + adjective + uncountable noun: such good weather

  • The film was so boring. (so + adjective)
  • It was such a boring film. (such a + adjective + noun)
  • They're such lovely people. (such + plural)
  • There were so many people at the party. (so many)

Common mistakes:

  • ❌ It was so a good party. → ✅ It was such a good party. (such a + noun)
  • ❌ The weather was such nice. → ✅ The weather was so nice. (so + adjective)
  • ❌ It was a such long day. → ✅ It was such a long day. (such a (word order))

Such + adjective + plural noun.

B2 · Upper-intermediate

So… that, such… that: results B2

PatternExample
so + adjective / adverb + (that)The film was so long (that) I fell asleep.
such (a) + adjective + noun + (that)It was such a long film (that) I fell asleep.
so much / many / few / little + noun + (that)There was so much traffic that we were late.

  • She was so tired that she fell asleep at her desk. (so… that)
  • It was such an easy exam that everyone passed. (such… that)
  • I had so much work that I couldn't go out. (so much… that)
  • The music was so loud I couldn't hear you. (that left out)

Common mistakes:

  • ❌ It was so hot day that we went to the beach. → ✅ It was such a hot day that we went to the beach. (such a + noun)
  • ❌ He spoke such quickly that I didn't understand. → ✅ He spoke so quickly that I didn't understand. (so + adverb)

So (result) or so that (purpose)? B2

MeaningExample
result: soIt started to rain, so we went home.
purpose: so thatI left early so that I could catch the train.
purpose in speech: so (= so that)Speak louder so everyone can hear.

  • The shop was closed, so we went home. (result)
  • I turned the music down so that the baby could sleep. (purpose)
  • She studied hard, so she passed. (result)
  • Write your email address here so that we can contact you. (purpose)

Common mistakes:

  • ❌ I saved money so that I can buy a car last year. → ✅ I saved money so that I could buy a car last year. (past purpose: could)
  • ❌ I was hungry so that I made a sandwich. → ✅ I was hungry, so I made a sandwich. (result: so)

C1 · Advanced

So good a book, such was the demand, so loud was the music C1

PatternExample
so + adjective + a / an + nounIt was so good a book that I read it twice. (= such a good book)
Such + be + noun + thatSuch was the demand that tickets sold out in minutes.
So + adjective + be + subject + thatSo loud was the music that the neighbours complained.
such that (formal)The design is such that it can be used anywhere.
so… as to + infinitiveHe was so foolish as to trust them.

  • Such was her talent that she won every prize. (such + inversion)
  • So heavy was the rain that the roads flooded. (so + inversion)
  • It was so difficult a question that nobody answered. (so + adjective + a + noun)
  • The problem is such that we need outside help. (such that)

Common mistakes:

  • ❌ So was the wind strong that trees fell. → ✅ So strong was the wind that trees fell. (So + adjective + be + subject)
  • ❌ It was so a difficult question. → ✅ It was so difficult a question. (so + adjective + a + noun)
