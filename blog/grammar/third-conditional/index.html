Third Conditional

Level: B1 · Free grammar guide

We use the third conditional to imagine a different past: something that didn't happen, and what its result would have been. If I had left earlier, I would have caught the train. (I didn't leave earlier, so I missed the train.)

We often use it to talk about regrets and to criticise: If you'd told me, I could have helped.

How to form the third conditional

If clause (the imagined past)Result (the imagined past result)
if + had + past participlewould have + past participle
If she had studied,she would have passed.
If we hadn't missed the bus,we wouldn't have been late.
If you had told me,I would have helped you.

You can change the order of the clauses. Use a comma only when the if clause comes first: If you had asked me, I would have helped. / I would have helped if you had asked me.

In speech we use contractions: If I'd known, I'd have told you. The first 'd = had; the second 'd = would. Would have often sounds like would've, but never write would of.

Could have and might have

Instead of would have, use could have for a possible ability and might have for a possible (not certain) result:

  1. If you had told me, I could have helped. (= I would have been able to help)
  2. If it had stopped raining, we might have gone to the beach. (= maybe we would have gone)

Questions and negatives

  1. What would you have done if you had lost your passport? (question)
  2. Would you have come if I'd invited you? (yes/no question)
  3. If he hadn't called, I wouldn't have known. (negatives in both clauses)

Third conditional or second conditional?

Second conditionalThird conditional
Timenow or the future (imagined)the past (imagined)
Formif + past simple, would + base verbif + past perfect, would have + past participle
ExampleIf I had more time, I would visit you.If I had had more time, I would have visited you.

Had had is correct. The first had makes the past perfect; the second is the past participle of have.

Examples

  1. If I had known about the party, I would have come. (I didn't know, so I didn't come)
  2. If it hadn't rained, we would have played tennis. (it rained, so we didn't play)
  3. We would have won the game if our best player hadn't been injured. (result clause first: no comma)
  4. If you had asked me, I could have helped you. (could have = possible)
  5. If they had booked earlier, they might have found a cheaper hotel. (might have = maybe)
  6. What would you have done if you had missed the flight? (question)
  7. If I'd set an alarm, I wouldn't have overslept. ('d = had)
  8. He wouldn't have crashed if he had driven more carefully. (criticism)
  9. If I had saved more money, I could have bought a car. (regret)
  10. If you hadn't reminded me, I would have forgotten her birthday. (you reminded me, so I remembered)

Common mistakes

❌ If I would have known, I would have come.

✅ If I had known, I would have come. (Don't use would in the if clause. You may hear it in casual speech, but it isn't correct in standard English.)

❌ If she had studied, she would passed.

✅ If she had studied, she would have passed. (The result needs would have + past participle.)

❌ If I had knew, I would have told you.

✅ If I had known, I would have told you. (Use the past participle after had: known, not knew.)

❌ I would of helped you.

✅ I would have helped you. (Would of is a spelling mistake for would've (would have).)

❌ If we had left earlier, we would catch the train yesterday.

✅ If we had left earlier, we would have caught the train yesterday. (The result is in the past too.)

❌ If he has called me, I would have answered.

✅ If he had called me, I would have answered. (The if clause needs the past perfect: had + past participle.)

Exercises (16)

Choose the correct answer.

1. If I ___ about the traffic, I would have taken the train.
The if clause uses the past perfect: had + past participle. Don't use would in the if clause.
2. If you had asked me, I ___ you with your homework last night.
The result is in the past (last night): would have + past participle.
3. If she ___ the bus, she wouldn't have been late for the interview.
Negative if clause: hadn't + past participle.
4. We ___ last night's match if our goalkeeper hadn't been injured.
The match was last night, so the result is in the past: would have won.
5. Choose the correct sentence.
If + had seen (past participle), result would have said.
6. If it hadn't rained on Sunday, we ___ a picnic.
Sunday is in the past, so the result is would have + past participle (had).
7. If I'd known you were vegetarian, I ___ meat.
Imagined past result: wouldn't have + past participle.
8. What ___ if you had lost your passport?
Question: question word + would + subject + have + past participle.
9. If they had booked earlier, they ___ a cheaper flight. (maybe, not certain)
Might have + past participle = a possible result in the past.
10. He would have passed the exam if he ___ harder.
If clause: had + past participle. Would goes in the other clause.
11. I wouldn't have known about the job if my friend ___ me.
Negative if clause: hadn't + past participle.
12. If you had told me earlier, I ___ you, but now it's too late.
Could have + past participle = it was possible in the past, but it didn't happen.
13. If I'd known, I'd have called you. What does the first 'd mean?
In the if clause, 'd = had (If I had known). In the result clause, 'd = would.
14. If I ___ an alarm, I wouldn't have overslept.
Set is irregular: set → set → set. (Sat is the past of sit.)
15. Which sentence means: I didn't have time, so I didn't call you?
Imagined past = third conditional: If I'd had time, I would have called you.
16. If the weather ___ better, we would have stayed longer.
The if clause needs the past perfect: had been.
