Third Conditional (If I had known…, I would have…)

B1 · B2 · C1

We use the third conditional to imagine a different past: something that didn't happen, and what the result would have been. If I had known you were ill, I would have visited you. (I didn't know, so I didn't visit.)

It's often used for regrets, criticism and relief. For imaginary situations now, see Second Conditional. To mix past and present, see Mixed Conditionals.

B1 · Intermediate

Form and use: if + past perfect, would have + past participle B1

if-clause (past perfect)main clause (would have + past participle)
If I had studied harder,I would have passed the exam.
If she hadn't missed the bus,she wouldn't have been late.
If you had told me,I would have helped you.

  • If it hadn't rained, we'd have had a picnic. (it rained, so no picnic)
  • If you had asked me, I would have said yes. (you didn't ask)
  • She wouldn't have got lost if she had taken a map. (if clause second)
  • What would you have done if you had missed the flight? (question)

Common mistakes:

  • ❌ If I would have known, I would have come. → ✅ If I had known, I would have come. (No would in the if clause.)
  • ❌ If you had told me, I would help you. → ✅ If you had told me, I would have helped you. (Past result: would have + past participle.)
  • ❌ If we had leave earlier, we would have arrived on time. → ✅ If we had left earlier, we would have arrived on time. (had + past participle)

'd = had or would? Contractions in the third conditional B1

  • If you'd asked me, I'd have helped. (had asked / would have helped)
  • She'd have come if she'd known. (would have come / had known)
  • If we'd left at six, we'd have missed the traffic. (had left / would have missed)
  • I would've told you if I'd remembered. (informal writing)

Common mistakes:

  • ❌ If I'd of known, I'd of come. → ✅ If I'd known, I'd have come. (never of)
  • ❌ If I'd have known, I'd have come. → ✅ If I'd known, I'd have come. (if clause: 'd = had, no have)

B2 · Upper-intermediate

Could have, might have in the result B2

  • could have + past participle = would have been able to: If I'd had a car, I could have driven you.
  • might have + past participle = perhaps would have: If you'd apologised, she might have forgiven you.

  • If we'd left earlier, we could have seen the sunset. (would have been able to)
  • If you'd been more careful, you might have won. (perhaps would have)
  • Without your help, I couldn't have done it. (negative)
  • If she had been able to get a visa, she would have come. (if clause)

Common mistakes:

  • ❌ If I had known, I could helped you. → ✅ If I had known, I could have helped you. (could have + past participle)
  • ❌ If you had tried, you might have win. → ✅ If you had tried, you might have won. (might have + past participle)

Continuous forms: If I hadn't been driving so fast… B2

  • If he hadn't been texting, he would have seen the car. (in progress)
  • If you had been listening, you would have understood. (you weren't listening)
  • If I hadn't taken this job, I would have been working in my dad's shop. (imagined activity)
  • If it hadn't been raining, we would have played outside. (situation in progress)

Common mistakes:

  • ❌ If I wasn't driving so fast, I wouldn't have crashed. → ✅ If I hadn't been driving so fast, I wouldn't have crashed. (Past: past perfect continuous.)
  • ❌ If she had been pay attention, she would have seen it. → ✅ If she had been paying attention, she would have seen it. (had been + -ing)

C1 · Advanced

If it hadn't been for…, But for…, Without… C1

  • If it hadn't been for the traffic, we'd have arrived on time. (the traffic made us late)
  • But for her quick thinking, the fire would have spread. (formal)
  • Without your advice, I would have made a terrible mistake. (without + noun)
  • Had it not been for the rain, the match would have finished. (inverted, very formal)

Common mistakes:

  • ❌ If it wasn't for the traffic, we would have arrived on time. → ✅ If it hadn't been for the traffic, we would have arrived on time. (Past: hadn't been for.)
  • ❌ But for his help, I will fail. → ✅ But for his help, I would have failed. (Past result: would have + past participle.)
