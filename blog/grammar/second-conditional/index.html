Second Conditional

Level: B1 · Free grammar guide

We use the second conditional to talk about unreal or unlikely situations in the present or future, and their results: If I had a million dollars, I'd buy a house by the sea. (I don't have a million dollars.)

Form

If clauseMain clauseExample
if + past simplewould + verbIf I lived in the city, I would walk to work.
if + past simplecould / might + verbIf I spoke Japanese, I could work in Tokyo.

Would is often contracted: I'd, you'd, she'd. The past tense here doesn't mean past time. It shows that the situation is unreal.

Don't use would in the if clause: If I had time… (not If I would have time).

If I were you

With be, you can use were for all persons: If I were rich… If she were here… (was is also common in everyday speech). If I were you, I'd… is a common way to give advice: If I were you, I'd talk to her.

First or second conditional?

First conditional (possible)Second conditional (unreal or unlikely)
If I win the match, I'll be happy. (I might win.)If I won the lottery, I'd stop working. (It's very unlikely.)
If it rains, we'll stay in.If I were taller, I'd play basketball. (I'm not tall.)

See Zero and First Conditional and Third Conditional.

Examples

  1. If I had more free time, I'd travel more. (unreal present)
  2. If she studied more, she would pass the exam. (unreal present)
  3. What would you do if you lost your phone? (question)
  4. If I were you, I'd accept the offer. (advice)
  5. If we lived by the sea, we could swim every day. (could)
  6. If I spoke Japanese, I might get a job in Tokyo. (might)
  7. If he didn't live so far away, I'd visit him more often. (negative if clause)
  8. I wouldn't do that if I were you. (main clause first)
  9. If people cycled more, there would be less traffic. (general unreal)
  10. Would you be angry if I borrowed your car? (polite question)

Common mistakes

❌ If I would have time, I would help you.

✅ If I had time, I would help you. (Past simple in the if clause, not would.)

❌ If I had time, I will help you.

✅ If I had time, I would help you. (Second conditional: would, not will.)

❌ If I am you, I'd talk to her.

✅ If I were you, I'd talk to her. (Unreal: If I were you.)

❌ If I knew the answer, I would told you.

✅ If I knew the answer, I would tell you. (Would + base form.)

❌ If he would study, he would pass.

✅ If he studied, he would pass. (Past simple in the if clause.)

Exercises (16)

Choose the correct answer.

1. If I ___ a million dollars, I'd buy a house by the sea.
Past simple in the if clause: had.
2. If she studied more, she ___ the exam.
Main clause: would pass.
3. If I ___ you, I'd talk to her.
Advice: If I were you.
4. What ___ you do if you lost your phone?
Question in the main clause: What would you do…?
5. If we lived in the city, we ___ walk to work.
Unreal possibility: could.
6. I'd travel more if I ___ more free time.
Past simple in the if clause: had.
7. If he ___ so far away, I'd visit him more often.
Negative past simple in the if clause: didn't live.
8. She ___ happier if she changed jobs.
Main clause: would be.
9. If you could live anywhere, where ___ you live?
Main clause question: where would you live?
10. Choose the correct sentence.
If + past simple, would + verb.
11. I wouldn't do that if I ___ you.
If I were you.
12. If people ___ more, there would be less traffic.
Past simple in the if clause: cycled.
13. If I spoke Japanese, I ___ get a job in Tokyo.
Unreal possibility: might.
14. 'If I win the match, I'll be happy.' This sentence is a ___.
If + present, will: first conditional, a real possibility.

Unreal present with be: weren't (or wasn't).

Past simple in the if clause: borrowed.
