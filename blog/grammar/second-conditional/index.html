شرطی نوع دومSecond Conditional (If I had…, I would…)

We use the second conditional for situations that are imaginary now or unlikely in the future: If I had a car, I'd drive to work. (I don't have a car.)

The if clause uses a past form, but the meaning is not past. For real, possible situations, see Zero and First Conditional. For the past, see Third Conditional.

A2 · مقدماتی

Form and use: if + past simple, would + verb A2

if + past simple, would + base verb for an imaginary or unlikely situation: If I won the lottery, I'd travel the world.

if-clause (past simple)main clause (would + base verb)
If I had more money,I would buy a new phone.
If we lived by the sea,we'd go swimming every day.
If she didn't work so hard,she wouldn't be so tired.

The past form in the if clause doesn't mean the past. It shows that the situation is not real or not likely: If I had a dog… = I don't have a dog.

The short form of would is 'd: I'd go, she'd help. The negative is wouldn't.

Don't use would in the if clause: If I had time… Not If I would have time…

  • If I had a car, I'd drive you to the airport. (I don't have a car)
  • If my brother lived nearer, we'd see each other more. (he lives far away)
  • If you didn't eat so much sugar, you'd feel better. (imaginary change)
  • I wouldn't do that if I were you. (if clause second)

اشتباه‌های رایج:

  • ❌ If I would have a lot of money, I would buy a boat. → ✅ If I had a lot of money, I would buy a boat. (No would in the if clause.)
  • ❌ If I won the lottery, I will buy a house. → ✅ If I won the lottery, I would buy a house. (Second conditional: would, not will.)
  • ❌ If I have wings, I would fly. → ✅ If I had wings, I would fly. (Imaginary: past simple after if.)

What would you do if…? A2

Questions: What would you do if you lost your phone? Short answers: Yes, I would. / No, I wouldn't.

To ask about an imaginary situation, use would + subject + base verb: What would you do if you lost your passport?

The if clause can come first: If you could live anywhere, where would you live?

Short answers use would / wouldn't: Would you help me if I asked? ~ Yes, I would.

In speaking, would you often sounds like /wʊdʒu/. Don't drop it: What would you do? Not What you would do?

  • What would you do if you won the lottery? (question)
  • If you met a famous person, who would you like to meet? (if clause first)
  • Would you move abroad if you had the chance? ~ Yes, I would. (yes/no question)
  • Where would you go if you had a free day? (wh-question)

اشتباه‌های رایج:

  • ❌ What you would do if you were rich? → ✅ What would you do if you were rich? (would before the subject)
  • ❌ What would you do if you would see a ghost? → ✅ What would you do if you saw a ghost? (No would in the if clause.)

تمرین سطح A2

1. If I ___ more free time, I would learn to paint.
If + past simple for an imaginary situation.
2. If we had a garden, we ___ vegetables.
Result: would + base verb.
3. If my phone ___ (not / be) so old, I wouldn't need a new one.
If + past simple (were is also correct).
4. What ___ you do if you found a wallet in the street?
Imaginary situation: What would you do…?
5. If you could have any job, which job ___?
Question order: would you choose.
6. ___ (you / accept) the job if they offered you more money?
Would + subject + base verb.

B1 · متوسط

First or second conditional? B1

First = a real possibility (If I win, I'll…). Second = imaginary or unlikely (If I won, I'd…). The speaker chooses.

First conditionalSecond conditional
If it rains tomorrow, we'll stay in. (it may rain)If it rained every day, I'd move to Spain. (imaginary)
If I get the job, I'll buy a car. (I've had an interview)If I got the job, I'd buy a car. (it's unlikely)
If you come to Toronto, you'll love it.If you lived in Toronto, you'd love it.

Sometimes both are possible. The choice shows how likely the speaker thinks the situation is: If I win the match, I'll be so happy (I think I can win). If I won the match, I'd be so happy (I probably won't).

For something that is impossible or not true now, only the second conditional works: If I were 20 years younger… Not If I am 20 years younger…

  • If I see Mina at school, I'll tell her. (I'll probably see her)
  • If I had Mina's number, I'd call her. (I don't have it)
  • If he apologises, I'll forgive him. (it's possible)
  • If I were the president, I'd change the law. (imaginary)

اشتباه‌های رایج:

  • ❌ If I am a bird, I would fly to you. → ✅ If I were a bird, I would fly to you. (Impossible: second conditional.)
  • ❌ If it rained tomorrow, we will cancel the trip. → ✅ If it rains tomorrow, we'll cancel the trip. (Don't mix: if + present, will (or if + past, would).)

Could and might in the second conditional B1

Use could (= would be able to) or might (= perhaps would) in the result: If I had time, I could help. If I could… in the if clause = if I was able to.

In the main clause, could means would be able to, and might means perhaps would: If I had a car, I could drive you home. If you asked him nicely, he might say yes.

In the if clause, could means was able to: If I could speak Japanese, I'd work in Tokyo.

Don't use would and could together for the same verb: If I could swim, I'd go to the beach. Not If I would could swim…

  • If I had more space, I could have a dog. (would be able to)
  • If you talked to her, she might understand. (perhaps would)
  • If I could play the guitar, I'd join a band. (if I was able to)
  • We could go out for dinner if you weren't so tired. (would be able to)

اشتباه‌های رایج:

  • ❌ If I can drive, I would buy a car. → ✅ If I could drive, I would buy a car. (Imaginary: could in the if clause.)
  • ❌ If you asked him, he might helps. → ✅ If you asked him, he might help. (might + base verb)

Giving advice: If I were you… B1

If I were you, I'd… gives advice. I'd… alone, or If I were in your position…, also work.

A very common way to give advice: If I were you, I'd + base verb: If I were you, I'd talk to your manager.

Often the if clause is left out: I'd see a doctor. I wouldn't worry about it.

More formal: If I were in your position / in your shoes, I would…

In this phrase, were is the normal form, even in everyday English. If I was you is heard, but it's very informal. See Was and Were.

  • If I were you, I'd take the train. It's faster. (advice)
  • I wouldn't buy that car. It's too expensive. (if clause left out)
  • If I were in your position, I'd ask for a pay rise. (more formal)
  • What would you do if you were me? (asking for advice)

اشتباه‌های رایج:

  • ❌ If I am you, I will call her. → ✅ If I were you, I'd call her. (Advice: If I were you, I'd…)
  • ❌ If I were you, I take a taxi. → ✅ If I were you, I'd take a taxi. (Result: would + base verb.)

C1 · پیشرفته

If I were to…, If it weren't for… C1

If + were to + verb makes a future situation more hypothetical or polite. If it weren't for… = without…

If … were to + base verb presents a future event as unlikely or purely hypothetical. It is more formal: If the company were to close, 500 people would lose their jobs.

It also makes suggestions softer: If you were to move your car, we could get the van in.

If it weren't for + noun = without this thing, the situation now would be different: If it weren't for my sister, I'd be lonely. (My sister is the reason I'm not lonely.)

In formal English, these can be inverted: Were the company to close… Were it not for my sister… See Inverted Conditionals.

  • If you were to win the election, what would you change first? (hypothetical future)
  • If prices were to rise again, many families would struggle. (unlikely event)
  • If it weren't for the rain, this would be a perfect holiday. (without the rain)
  • If it weren't for your help, I'd never finish this project. (your help makes the difference)

اشتباه‌های رایج:

  • ❌ If he was to resigned, they would need a new manager. → ✅ If he were to resign, they would need a new manager. (were to + base verb)
  • ❌ If it wasn't for her, I will fail. → ✅ If it weren't for her, I would fail. (Result: would.)

تمرین سطح C1

16. If the government ___ to raise taxes, there would be protests.
If … were to + base verb.
17. What does If it weren't for the music, the film would be boring mean?
If it weren't for X = X is the reason things are different.
18. If it ___ (not / be) for my parents' support, I couldn't study abroad.
If it weren't for…
