Second Conditional (If I had…, I would…)

A2 · B1 · C1

We use the second conditional for situations that are imaginary now or unlikely in the future: If I had a car, I'd drive to work. (I don't have a car.)

The if clause uses a past form, but the meaning is not past. For real, possible situations, see Zero and First Conditional. For the past, see Third Conditional.

A2 · Elementary

Form and use: if + past simple, would + verb A2

if-clause (past simple)main clause (would + base verb)
If I had more money,I would buy a new phone.
If we lived by the sea,we'd go swimming every day.
If she didn't work so hard,she wouldn't be so tired.

  • If I had a car, I'd drive you to the airport. (I don't have a car)
  • If my brother lived nearer, we'd see each other more. (he lives far away)
  • If you didn't eat so much sugar, you'd feel better. (imaginary change)
  • I wouldn't do that if I were you. (if clause second)

Common mistakes:

  • ❌ If I would have a lot of money, I would buy a boat. → ✅ If I had a lot of money, I would buy a boat. (No would in the if clause.)
  • ❌ If I won the lottery, I will buy a house. → ✅ If I won the lottery, I would buy a house. (Second conditional: would, not will.)
  • ❌ If I have wings, I would fly. → ✅ If I had wings, I would fly. (Imaginary: past simple after if.)

What would you do if…? A2

  • What would you do if you won the lottery? (question)
  • If you met a famous person, who would you like to meet? (if clause first)
  • Would you move abroad if you had the chance? ~ Yes, I would. (yes/no question)
  • Where would you go if you had a free day? (wh-question)

Common mistakes:

  • ❌ What you would do if you were rich? → ✅ What would you do if you were rich? (would before the subject)
  • ❌ What would you do if you would see a ghost? → ✅ What would you do if you saw a ghost? (No would in the if clause.)

B1 · Intermediate

First or second conditional? B1

First conditionalSecond conditional
If it rains tomorrow, we'll stay in. (it may rain)If it rained every day, I'd move to Spain. (imaginary)
If I get the job, I'll buy a car. (I've had an interview)If I got the job, I'd buy a car. (it's unlikely)
If you come to Toronto, you'll love it.If you lived in Toronto, you'd love it.

  • If I see Mina at school, I'll tell her. (I'll probably see her)
  • If I had Mina's number, I'd call her. (I don't have it)
  • If he apologises, I'll forgive him. (it's possible)
  • If I were the president, I'd change the law. (imaginary)

Common mistakes:

  • ❌ If I am a bird, I would fly to you. → ✅ If I were a bird, I would fly to you. (Impossible: second conditional.)
  • ❌ If it rained tomorrow, we will cancel the trip. → ✅ If it rains tomorrow, we'll cancel the trip. (Don't mix: if + present, will (or if + past, would).)

Could and might in the second conditional B1

  • If I had more space, I could have a dog. (would be able to)
  • If you talked to her, she might understand. (perhaps would)
  • If I could play the guitar, I'd join a band. (if I was able to)
  • We could go out for dinner if you weren't so tired. (would be able to)

Common mistakes:

  • ❌ If I can drive, I would buy a car. → ✅ If I could drive, I would buy a car. (Imaginary: could in the if clause.)
  • ❌ If you asked him, he might helps. → ✅ If you asked him, he might help. (might + base verb)

Giving advice: If I were you… B1

  • If I were you, I'd take the train. It's faster. (advice)
  • I wouldn't buy that car. It's too expensive. (if clause left out)
  • If I were in your position, I'd ask for a pay rise. (more formal)
  • What would you do if you were me? (asking for advice)

Common mistakes:

  • ❌ If I am you, I will call her. → ✅ If I were you, I'd call her. (Advice: If I were you, I'd…)
  • ❌ If I were you, I take a taxi. → ✅ If I were you, I'd take a taxi. (Result: would + base verb.)

C1 · Advanced

If I were to…, If it weren't for… C1

  • If you were to win the election, what would you change first? (hypothetical future)
  • If prices were to rise again, many families would struggle. (unlikely event)
  • If it weren't for the rain, this would be a perfect holiday. (without the rain)
  • If it weren't for your help, I'd never finish this project. (your help makes the difference)

Common mistakes:

  • ❌ If he was to resigned, they would need a new manager. → ✅ If he were to resign, they would need a new manager. (were to + base verb)
  • ❌ If it wasn't for her, I will fail. → ✅ If it weren't for her, I would fail. (Result: would.)
