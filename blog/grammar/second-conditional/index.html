شرطی نوع دومSecond Conditional (If I had…, I would…)

شرطی نوع دوم را برای موقعیت‌هایی به کار می‌بریم که الان خیالی‌اند یا در آینده بعید: If I had a car, I'd drive to work. (ماشین ندارم.)

بخشِ if شکل گذشته دارد، اما معنی‌اش گذشته نیست (مثل فارسی: «اگر ماشین داشتم…»). برای موقعیت‌های واقعی و ممکن صفحهٔ شرطی نوع صفر و نوع اول و برای گذشته صفحهٔ شرطی نوع سوم را ببینید.

A2 · B1 · C1

A2 · مقدماتی

ساختار و کاربرد: if + گذشتهٔ ساده، would + فعل A2

if + گذشتهٔ ساده، would + شکل سادهٔ فعل برای موقعیتی خیالی یا بعید: If I won the lottery, I'd travel the world.

بخشِ if (گذشتهٔ ساده)بخشِ اصلی (would + شکل سادهٔ فعل)
If I had more money,I would buy a new phone.
If we lived by the sea,we'd go swimming every day.
If she didn't work so hard,she wouldn't be so tired.

شکل گذشته در بخشِ if به معنی گذشته نیست؛ نشان می‌دهد موقعیت واقعی نیست یا بعید است: If I had a dog… یعنی سگ ندارم.

شکل کوتاهِ would می‌شود 'd: I'd go, she'd help. منفی‌اش wouldn't است.

در بخشِ if حرف would نیاورید: If I had time… نه If I would have time…

  • If I had a car, I'd drive you to the airport. ماشین ندارم
  • If my brother lived nearer, we'd see each other more. دور زندگی می‌کند
  • If you didn't eat so much sugar, you'd feel better. تغییری خیالی
  • I wouldn't do that if I were you. بخشِ if دوم آمده

اشتباه‌های رایج:

  • ❌ If I would have a lot of money, I would buy a boat. → ✅ If I had a lot of money, I would buy a boat. در بخشِ if حرف would نمی‌آید.
  • ❌ If I won the lottery, I will buy a house. → ✅ If I won the lottery, I would buy a house. شرطی نوع دوم: would، نه will.
  • ❌ If I have wings, I would fly. → ✅ If I had wings, I would fly. خیالی: بعد از if گذشتهٔ ساده.

What would you do if…? A2

سؤالی: What would you do if you lost your phone? جواب کوتاه: Yes, I would. / No, I wouldn't.

برای پرسیدن دربارهٔ یک موقعیت خیالی، would + فاعل + شکل سادهٔ فعل بیاورید: What would you do if you lost your passport?

بخشِ if می‌تواند اول بیاید: If you could live anywhere, where would you live?

جواب کوتاه با would / wouldn't می‌آید: Would you help me if I asked? ~ Yes, I would.

در گفتار، would you اغلب شبیه /wʊdʒu/ شنیده می‌شود. آن را حذف نکنید: What would you do? نه What you would do?

  • What would you do if you won the lottery? سؤالی
  • If you met a famous person, who would you like to meet? بخشِ if اول آمده
  • Would you move abroad if you had the chance? ~ Yes, I would. سؤال بله/نه
  • Where would you go if you had a free day? سؤال با کلمهٔ پرسشی

اشتباه‌های رایج:

  • ❌ What you would do if you were rich? → ✅ What would you do if you were rich? would قبل از فاعل
  • ❌ What would you do if you would see a ghost? → ✅ What would you do if you saw a ghost? در بخشِ if حرف would نمی‌آید.

تمرین سطح A2

1. If I ___ more free time, I would learn to paint.
برای موقعیت خیالی: if + گذشتهٔ ساده.
2. If we had a garden, we ___ vegetables.
نتیجه: would + شکل سادهٔ فعل.
3. If my phone ___ (not / be) so old, I wouldn't need a new one.
if + گذشتهٔ ساده (were هم درست است).
4. What ___ you do if you found a wallet in the street?
موقعیت خیالی: What would you do…?
5. If you could have any job, which job ___?
ترتیب سؤال: would you choose.
6. ___ (you / accept) the job if they offered you more money?
would + فاعل + شکل سادهٔ فعل.

B1 · متوسط

شرطی نوع اول یا نوع دوم؟ B1

نوع اول یعنی احتمالِ واقعی (If I win, I'll…). نوع دوم یعنی خیالی یا بعید (If I won, I'd…). انتخاب با گوینده است.

شرطی نوع اولشرطی نوع دوم
If it rains tomorrow, we'll stay in. (ممکن است ببارد)If it rained every day, I'd move to Spain. (خیالی)
If I get the job, I'll buy a car. (مصاحبه داده‌ام)If I got the job, I'd buy a car. (بعید است)
If you come to Toronto, you'll love it.If you lived in Toronto, you'd love it.

گاهی هر دو ممکن‌اند. انتخاب نشان می‌دهد گوینده موقعیت را چقدر محتمل می‌داند: If I win the match, I'll be so happy (فکر می‌کنم می‌توانم ببرم). If I won the match, I'd be so happy (احتمالاً نمی‌برم).

برای چیزی که غیرممکن است یا الان درست نیست، فقط شرطی نوع دوم درست است: If I were 20 years younger… نه If I am 20 years younger…

  • If I see Mina at school, I'll tell her. احتمالاً می‌بینمش
  • If I had Mina's number, I'd call her. شماره‌اش را ندارم
  • If he apologises, I'll forgive him. ممکن است
  • If I were the president, I'd change the law. خیالی

اشتباه‌های رایج:

  • ❌ If I am a bird, I would fly to you. → ✅ If I were a bird, I would fly to you. غیرممکن: شرطی نوع دوم.
  • ❌ If it rained tomorrow, we will cancel the trip. → ✅ If it rains tomorrow, we'll cancel the trip. قاطی نکنید: if + حال با will (یا if + گذشته با would).

could و might در شرطی نوع دوم B1

در نتیجه could (یعنی «می‌توانستم») یا might (یعنی «شاید…») بیاورید: If I had time, I could help. در بخشِ if، If I could… یعنی «اگر می‌توانستم».

در بخش اصلی، could یعنی would be able to («می‌توانستم») و might یعنی perhaps would («شاید»): If I had a car, I could drive you home. If you asked him nicely, he might say yes.

در بخشِ if، could یعنی was able to («می‌توانستم»): If I could speak Japanese, I'd work in Tokyo.

would و could را برای یک فعل با هم نیاورید: If I could swim, I'd go to the beach. نه If I would could swim…

  • If I had more space, I could have a dog. می‌توانستم
  • If you talked to her, she might understand. شاید
  • If I could play the guitar, I'd join a band. اگر می‌توانستم
  • We could go out for dinner if you weren't so tired. می‌توانستیم

اشتباه‌های رایج:

  • ❌ If I can drive, I would buy a car. → ✅ If I could drive, I would buy a car. خیالی: در بخشِ if حرف could.
  • ❌ If you asked him, he might helps. → ✅ If you asked him, he might help. might + شکل سادهٔ فعل

نصیحت کردن: If I were you… B1

If I were you, I'd… یعنی «اگر جای تو بودم…» و برای نصیحت است. خودِ I'd… یا If I were in your position… هم درست است.

یک راه خیلی رایج برای نصیحت: If I were you, I'd + شکل سادهٔ فعل: If I were you, I'd talk to your manager.

اغلب بخشِ if را حذف می‌کنند: I'd see a doctor. I wouldn't worry about it.

رسمی‌تر: If I were in your position / in your shoes, I would…

در این عبارت، were شکل معمول است، حتی در انگلیسی روزمره. If I was you هم شنیده می‌شود، اما خیلی خودمانی است. صفحهٔ was و were را ببینید.

  • If I were you, I'd take the train. It's faster. نصیحت
  • I wouldn't buy that car. It's too expensive. بخشِ if حذف شده
  • If I were in your position, I'd ask for a pay rise. رسمی‌تر
  • What would you do if you were me? نظر خواستن

اشتباه‌های رایج:

  • ❌ If I am you, I will call her. → ✅ If I were you, I'd call her. نصیحت: If I were you, I'd…
  • ❌ If I were you, I take a taxi. → ✅ If I were you, I'd take a taxi. نتیجه: would + شکل سادهٔ فعل.

C1 · پیشرفته

If I were to…, If it weren't for… C1

If + were to + verb makes a future situation more hypothetical or polite. If it weren't for… = without…

If … were to + base verb presents a future event as unlikely or purely hypothetical. It is more formal: If the company were to close, 500 people would lose their jobs.

It also makes suggestions softer: If you were to move your car, we could get the van in.

If it weren't for + noun = without this thing, the situation now would be different: If it weren't for my sister, I'd be lonely. (My sister is the reason I'm not lonely.)

In formal English, these can be inverted: Were the company to close… Were it not for my sister… See Inverted Conditionals.

  • If you were to win the election, what would you change first? (hypothetical future)
  • If prices were to rise again, many families would struggle. (unlikely event)
  • If it weren't for the rain, this would be a perfect holiday. (without the rain)
  • If it weren't for your help, I'd never finish this project. (your help makes the difference)

اشتباه‌های رایج:

  • ❌ If he was to resigned, they would need a new manager. → ✅ If he were to resign, they would need a new manager. (were to + base verb)
  • ❌ If it wasn't for her, I will fail. → ✅ If it weren't for her, I would fail. (Result: would.)
