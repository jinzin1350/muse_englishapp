Zero and First Conditional

Level: A2 · Free grammar guide

Use the Zero Conditional for things that are always true — general facts, scientific truths, habits. Use the First Conditional for real future possibilities — things that might happen. Both use the Present Simple in the if clause; the difference is the result clause.

How to form the zero and first conditional

Zero Conditional — general truths

  • Form: If + Present Simple, Present Simple
  • If you heat water to 100°C, it boils.
  • If I don't sleep well, I feel tired.

First Conditional — real future possibility

  • Form: If + Present Simple, will + base verb
  • If it rains tomorrow, we will stay home.
  • If you study tonight, you will pass the test.

Both orders work:

  • We will stay home if it rains tomorrow. (result first, no comma)
  • If it rains tomorrow, we will stay home. (condition first, comma)

Future time clauses: After when, as soon as, until, before, after, use Present Simple for future meaning, not will: When I arrive, I will call you. (Not: When I will arrive...)

Zero vs First for general truths: Both can describe general truths. If you heat water, it boils (zero — a scientific fact). If you heat the water, it will boil (first — the same fact, framed as a prediction about what will happen). The difference is emphasis, not correctness. When the situation is clearly in the future, First Conditional is more natural: If you heat the water now, it will boil in two minutes.

Examples

  1. If you press this button, the machine starts. (Zero — always true.)
  2. If you press that button, you will start the machine. (First — a prediction about this moment.)
  3. If it rains, the grass gets wet. (Zero — general fact.)
  4. If it rains tonight, we will cancel the barbecue. (First — a future plan.)
  5. If I drink coffee late, I can't sleep. (Zero — a personal habit.)
  6. If I drink coffee now, I won't sleep tonight. (First — tonight's result.)
  7. If you don't water plants, they die. (Zero — always true.)
  8. If you don't water the plants this week, they will die. (First — this week's future.)
  9. When the bell rings, the lesson ends. (Zero — routine.)
  10. When I finish this book, I will start a new one. (First — future plan, when + Present Simple.)

    11. Common mistakes

    ❌ If it will rain, we will stay home.

    ✅ If it rains, we will stay home. (In the if clause, use Present Simple, not will — even for future meaning.)

    ❌ If you heat water, it will boils.

    ✅ If you heat water, it boils. / it will boil. (After will, use the base verb (boil, not boils). Zero and first conditional are both fine here.)

    ❌ If I will see him, I tell him.

    ✅ If I see him, I will tell him. (If clause: Present Simple. Result: will + base verb.)

    ❌ When I will arrive, I will call you.

    ✅ When I arrive, I will call you. (After when for future meaning, use Present Simple.)
