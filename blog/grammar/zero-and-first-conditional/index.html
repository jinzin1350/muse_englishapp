Zero and First Conditional

Level: A2 · Free grammar guide

The zero conditional talks about things that are always true: If you heat ice, it melts.

The first conditional talks about a real possibility in the future: If it rains tomorrow, we'll stay at home.

Form

If clauseMain clauseExample
Zeroif + present simplepresent simpleIf you mix red and white, you get pink.
Firstif + present simplewill / can / might + verb, or an imperativeIf you study, you'll pass. If you're cold, close the window.

Don't use will in the if clause: If it rains… (not If it will rain).

The clauses can go in either order. Use a comma when if comes first: If you hurry, you'll catch the bus. / You'll catch the bus if you hurry.

If, when and unless

  • if = maybe it will happen: If I see Tom, I'll tell him.
  • when = I'm sure it will happen: I'll call you when I get home. (present tense after when too)
  • unless = if not: You can't come in unless you have a ticket. (= if you don't have a ticket)

Examples

  1. If you heat water to 100°C, it boils. (zero: always true)
  2. Plants die if they don't get water. (zero)
  3. When the sun goes down, it gets cooler. (zero with when)
  4. If it rains tomorrow, we'll stay at home. (first)
  5. If she gets the job, she'll move to London. (first)
  6. We'll be late if we don't leave now. (first, if second)
  7. If you have any questions, ask your teacher. (first + imperative)
  8. If you're free tomorrow, we can go to the cinema. (first + can)
  9. Unless you hurry, you'll miss the bus. (unless = if not)
  10. I'll call you when I get home. (when + present)

Common mistakes

❌ If it will rain, we'll stay at home.

✅ If it rains, we'll stay at home. (Present simple in the if clause.)

❌ If you will help me, I finish early.

✅ If you help me, I'll finish early. (If + present, will + verb.)

❌ I'll call you when I will get home.

✅ I'll call you when I get home. (Present tense after when for the future.)

❌ Unless you don't hurry, you'll be late.

✅ Unless you hurry, you'll be late. (Unless already means if not.)

❌ If you study, you would pass.

✅ If you study, you'll pass. (First conditional: will, not would.)

Exercises (16)

Choose the correct answer.

1. If you heat water to 100°C, it ___.
Zero conditional (always true): present simple, boils.
2. If it ___ tomorrow, we'll stay at home.
Present simple in the if clause: rains.
3. If you study hard, you ___ the exam.
First conditional: will pass.
4. I'll call you when I ___ home.
Present after when for the future: get.
5. ___ you hurry, you'll miss the bus.
If you don't hurry = Unless you hurry.
6. If you mix red and white, you ___ pink.
Zero conditional: present simple, get.
7. If she ___ the job, she'll move to London.
Present simple in the if clause: gets.
8. If you're cold, ___ the window.
Imperative in the main clause: close.
9. Plants die if they ___ water.
Zero conditional: present simple, don't get.
10. We ___ late if we don't leave now.
First conditional: will be.
11. ___ I see her tomorrow, I'll give her the book. I'm not sure she'll be there.
Not sure it will happen: If.
12. When the sun goes down, it ___ cooler.
Always true: present simple, gets.
13. Choose the correct sentence.
If + present, will + verb.
14. If I see Tom, I ___ him your message.
First conditional: 'll give.
15. You can't come in ___ you have a ticket.
If you don't have = unless you have.
16. If you ___ any questions, ask your teacher.
Present simple in the if clause: have.
