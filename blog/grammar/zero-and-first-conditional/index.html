Zero and First Conditional

A2 · B1 · B2 · C1

Real conditionals talk about situations that are true or possible. The zero conditional is for things that are always true: If you heat ice, it melts. The first conditional is for a possible future situation: If it rains tomorrow, we'll stay at home.

In both, the if clause uses a present tense, even when we mean the future. For imaginary situations, see Second Conditional.

A2 · Elementary

Zero conditional: always true A2

if-clausemain clause
If you heat water to 100°C,it boils.
If I drink coffee at night,I can't sleep.
If you press this button,the machine stops.

  • If you don't water plants, they die. (a fact)
  • If my son eats chocolate, he gets a headache. (always happens)
  • Ice melts if you leave it in the sun. (if clause second, no comma)
  • If you feel sick, call the doctor. (instruction)

Common mistakes:

  • ❌ If you will heat ice, it melts. → ✅ If you heat ice, it melts. (No will in the if clause.)
  • ❌ If you mix blue and yellow, you will get green. (a general fact) → ✅ If you mix blue and yellow, you get green. (A general truth: present in both clauses.)

First conditional: a possible future A2

if-clause (present)main clause (will + base verb)
If it rains tomorrow,we'll stay at home.
If you don't hurry,you'll miss the bus.
If she calls,I'll tell her.

  • If you study hard, you'll pass the exam. (likely result)
  • We'll miss the train if we don't leave now. (if clause second)
  • What will you do if the shop is closed? (question)
  • If I see Ali, I'll give him your message. (possible future)

Common mistakes:

  • ❌ If it will be sunny, we'll go to the beach. → ✅ If it's sunny, we'll go to the beach. (No will after if.)
  • ❌ If you will come, I am happy. → ✅ If you come, I'll be happy. (Present in the if clause, will in the result.)

Practice: A2

1. If you ___ water below 0°C, it freezes.
Zero conditional: if + present simple.
2. If people don't sleep enough, they ___ tired.
A general truth: present simple.
3. If you ___ (press) this key, the screen turns off.
If + present simple.
4. If you ___ now, you'll catch the bus.
If + present simple.
5. If it snows tomorrow, we ___ to school.
Result in the future: won't + base verb.
6. If I ___ (have) time this weekend, I'll visit my grandmother.
If + present simple.

B1 · Intermediate

First conditional with can, might, should and imperatives B1

  • modals: If you finish early, you can go home. If it's cold, we might stay in. If you feel ill, you should see a doctor.
  • be going to: If the weather's bad, we're going to cancel.
  • imperatives: If you see Sara, tell her to call me. If you're cold, close the window.

  • If you need help, call me. (imperative)
  • If the price goes down, we might buy it. (less certain)
  • If you 've finished your work, you can go. (present perfect in the if clause)
  • If you 're going to the shop, can you buy some milk? (present continuous + request)

Common mistakes:

  • ❌ If you will need help, call me. → ✅ If you need help, call me. (No will in the if clause.)
  • ❌ If you'll have finished, you can go. → ✅ If you've finished, you can go. (Present perfect, not will.)

If or when? B1

when (sure)if (possible)
I'll call you when I get home. (I will get home.)I'll call you if I'm late. (Maybe I'll be late.)
When the film finishes, we'll go for dinner.If the film is boring, we'll leave.

  • When I see Maryam tomorrow, I'll ask her. (I'm going to see her)
  • If I see Maryam, I'll ask her. (maybe I'll see her)
  • When it gets dark, we'll light the fire. (it will get dark)
  • If it's cold, we'll light the fire. (maybe it will be cold)

Common mistakes:

  • ❌ I'll phone you if I get home. (I'm sure I'll get home) → ✅ I'll phone you when I get home. (Sure to happen: when)
  • ❌ When I will finish, I'll call you. → ✅ When I finish, I'll call you. (No will after when)

Practice: B1

Possible but not sure: might.
9. If you ___ (finish) your homework, you can watch TV.
If + present perfect (or present simple).

You will certainly get home: when.
11. ___ you need any help, just ask.

Sure to happen: when.

B2 · Upper-intermediate

Real conditionals with other tenses B2

  • past + present: If you were at the meeting, you know the plan. (Maybe you were there.)
  • past + past: If it rained, we stayed inside. (= whenever it rained, in the past)
  • present + past: If he's here now, he took the early train. (deduction)
  • present continuous: If she's arriving at 6, we should leave now.

  • If you saw the match last night, you know how good she is. (maybe you saw it)
  • When I was a child, if it snowed, we built snowmen. (past habit)
  • If he didn't come to class yesterday, he won't know about the test. (real past + future)
  • If you're feeling better, you can come with us. (present continuous)

Common mistakes:

  • ❌ If you saw the film, you would know the ending. (you may have seen it: a real question) → ✅ If you saw the film, you know the ending. (A real possibility: normal present tense.)
  • ❌ When I was young, if I was bored, I will read. → ✅ When I was young, if I was bored, I read. (Past habit: past in both clauses.)

Practice: B2

13. If you ___ the email I sent yesterday, you already know about the change.
A real past possibility: past simple.
14. When we were kids, if it ___, we played board games.
A past habit: past + past.
15. If she ___ (leave) at 8, she'll be here by now.
A real past possibility: past simple.

C1 · Advanced

If you'll wait…: will and should in real if-clauses C1

  • Willingness / polite requests: If you'll follow me, I'll show you to your room. (= if you are willing to)
  • Insistence (stressed will): If you will eat so much, of course you feel sick! (= if you insist on)
  • A result that comes later than the main clause: I'll lend you the money if it'll help you. (The help comes after the lending.)

  • If you'll just sign here, we can finish the paperwork. (polite request)
  • I'll take the job if it'll help my career. (result later)
  • If you should have any questions, please contact us. (less likely, formal)
  • If you happen to see my keys, let me know. (by chance)

Common mistakes:

  • ❌ If it will rain tomorrow, we'll stay at home. → ✅ If it rains tomorrow, we'll stay at home. (A simple future condition: no will.)
  • ❌ If you should to need help, call me. → ✅ If you should need help, call me. (should + base verb)

Practice: C1

16. A receptionist says: If you ___ take a seat, Dr Ahmadi will see you shortly.
Polite request: If you'll… (= if you are willing to).
17. If you should need anything, just call reception. This means:
If … should = less likely, polite.
18. If you ___ (happen) to see a pharmacy, could you get me some aspirin?
If you happen to… = if by chance.
