شرطی نوع صفر و نوع اولZero and First Conditional

شرطی‌های واقعی دربارهٔ موقعیت‌هایی‌اند که درست یا ممکن‌اند. شرطی نوع صفر برای چیزهایی است که همیشه درست‌اند: If you heat ice, it melts. شرطی نوع اول برای یک موقعیتِ ممکن در آینده است: If it rains tomorrow, we'll stay at home.

در هر دو، بخشِ if با زمان حال می‌آید، حتی وقتی منظورمان آینده است. برای موقعیت‌های خیالی صفحهٔ شرطی نوع دوم را ببینید.

A2 · مقدماتی

شرطی نوع صفر: همیشه درست A2

if / when + حال ساده، حال ساده برای واقعیت‌ها و چیزهایی که همیشه اتفاق می‌افتند: If you mix red and white, you get pink.

شرطی نوع صفر حقیقت‌های کلی، واقعیت‌های علمی و چیزهایی را توصیف می‌کند که در یک موقعیت همیشه اتفاق می‌افتند:

بخشِ ifبخشِ اصلی
If you heat water to 100°C,it boils.
If I drink coffee at night,I can't sleep.
If you press this button,the machine stops.

در شرطی نوع صفر، if همان معنی when یا whenever («هر وقت») را دارد: When you heat water to 100°C, it boils.

برای دستورالعمل، بخش اصلی می‌تواند امری باشد: If the alarm rings, leave the building.

جای دو بخش می‌تواند عوض شود. فقط وقتی بخشِ if اول می‌آید ویرگول بگذارید: If it rains, the roads get wet. / The roads get wet if it rains.

  • If you don't water plants, they die. واقعیت
  • If my son eats chocolate, he gets a headache. همیشه اتفاق می‌افتد
  • Ice melts if you leave it in the sun. بخشِ if دوم آمده، بدون ویرگول
  • If you feel sick, call the doctor. دستورالعمل

اشتباه‌های رایج:

  • ❌ If you will heat ice, it melts. → ✅ If you heat ice, it melts. در بخشِ if حرف will نمی‌آید.
  • ❌ If you mix blue and yellow, you will get green. (a general fact) → ✅ If you mix blue and yellow, you get green. حقیقت کلی: در هر دو بخش زمان حال.

شرطی نوع اول: آیندهٔ ممکن A2

if + حال ساده، will + شکل سادهٔ فعل برای یک احتمالِ واقعی در آینده: If it rains, we'll stay at home.

بخشِ if (حال)بخشِ اصلی (will + شکل سادهٔ فعل)
If it rains tomorrow,we'll stay at home.
If you don't hurry,you'll miss the bus.
If she calls,I'll tell her.

شرطی نوع اول دربارهٔ موقعیتی است که در آینده ممکن است پیش بیاید، و نتیجهٔ محتملِ آن.

در بخشِ if حال ساده بیاورید، با اینکه معنی آینده است. آنجا will نیاورید: If it rains… نه If it will rain… (در فارسی هم می‌گوییم «اگر باران بیاید»، نه «اگر باران خواهد آمد».)

سؤالی و منفی: What will you do if you don't pass? If you don't study, you won't pass.

بخشِ if می‌تواند اول یا دوم بیاید: I'll call you if I'm late. / If I'm late, I'll call you.

  • If you study hard, you'll pass the exam. نتیجهٔ محتمل
  • We'll miss the train if we don't leave now. بخشِ if دوم آمده
  • What will you do if the shop is closed? سؤالی
  • If I see Ali, I'll give him your message. آیندهٔ ممکن

اشتباه‌های رایج:

  • ❌ If it will be sunny, we'll go to the beach. → ✅ If it's sunny, we'll go to the beach. بعد از if حرف will نمی‌آید.
  • ❌ If you will come, I am happy. → ✅ If you come, I'll be happy. در بخشِ if حال، در نتیجه will.

تمرین سطح A2

1. If you ___ water below 0°C, it freezes.
شرطی نوع صفر: if + حال ساده.
2. If people don't sleep enough, they ___ tired.
حقیقت کلی: حال ساده.
3. If you ___ (press) this key, the screen turns off.
if + حال ساده.
4. If you ___ now, you'll catch the bus.
if + حال ساده.
5. If it snows tomorrow, we ___ to school.
نتیجه در آینده: won't + شکل سادهٔ فعل.
6. If I ___ (have) time this weekend, I'll visit my grandmother.
if + حال ساده.

B1 · متوسط

شرطی نوع اول با can, might, should و فعل امری B1

نتیجه می‌تواند با فعل‌های دیگر هم بیاید: If you're free, you can come. If it rains, we might stay in. If you see him, tell him.

بخش اصلی همیشه will ندارد. می‌توانیم این‌ها را بیاوریم:

  • فعل‌های وجهی: If you finish early, you can go home. If it's cold, we might stay in. If you feel ill, you should see a doctor.
  • be going to: If the weather's bad, we're going to cancel.
  • فعل امری: If you see Sara, tell her to call me. If you're cold, close the window.

بخشِ if می‌تواند حال استمراری یا حال کامل هم باشد: If you're waiting for the bus, it's late today. If you've finished, you can leave.

might و may نتیجه را از will نامطمئن‌تر می‌کنند: If we leave now, we'll arrive on time (مطمئن) / we might arrive on time (ممکن).

  • If you need help, call me. فعل امری
  • If the price goes down, we might buy it. نامطمئن‌تر
  • If you 've finished your work, you can go. حال کامل در بخشِ if
  • If you 're going to the shop, can you buy some milk? حال استمراری + درخواست

اشتباه‌های رایج:

  • ❌ If you will need help, call me. → ✅ If you need help, call me. در بخشِ if حرف will نمی‌آید.
  • ❌ If you'll have finished, you can go. → ✅ If you've finished, you can go. حال کامل، نه will.

if یا when؟ B1

when یعنی مطمئنید اتفاق می‌افتد. if یعنی ممکن است اتفاق بیفتد یا نیفتد. When I get home, I'll call you. If I get the job, I'll call you.

در جمله‌های آینده، بعد از when و if هر دو زمان حال می‌آید، اما معنی فرق دارد:

when (مطمئن)if (ممکن)
I'll call you when I get home. (حتماً به خانه می‌رسم.)I'll call you if I'm late. (شاید دیر کنم.)
When the film finishes, we'll go for dinner.If the film is boring, we'll leave.

در شرطی نوع صفر (حقیقت‌های کلی)، if و when تقریباً یک معنی دارند: If / When you heat ice, it melts.

بعد از when هم will نیاورید: When I arrive, I'll text you. نه When I will arrive. صفحهٔ جمله‌واره‌های زمانی آینده را ببینید.

  • When I see Maryam tomorrow, I'll ask her. حتماً می‌بینمش
  • If I see Maryam, I'll ask her. شاید ببینمش
  • When it gets dark, we'll light the fire. حتماً هوا تاریک می‌شود
  • If it's cold, we'll light the fire. شاید هوا سرد باشد

اشتباه‌های رایج:

  • ❌ I'll phone you if I get home. (I'm sure I'll get home) → ✅ I'll phone you when I get home. حتماً اتفاق می‌افتد: when
  • ❌ When I will finish, I'll call you. → ✅ When I finish, I'll call you. بعد از when حرف will نمی‌آید

تمرین سطح B1

ممکن اما نه قطعی: might.

if + حال کامل (یا حال ساده).

حتماً به خانه می‌رسید: when.

شاید کمک لازم داشته باشید: if.

حتماً اتفاق می‌افتد: when.

B2 · بالاتر از متوسط

Real conditionals with other tenses B2

Real conditionals can use any tense that makes sense: If you were at the meeting, you know the news. If she's arriving at 6, we should leave now.

A real conditional connects a condition and a result that are both real or possible. So we can use the tenses we need for the meaning:

  • past + present: If you were at the meeting, you know the plan. (Maybe you were there.)
  • past + past: If it rained, we stayed inside. (= whenever it rained, in the past)
  • present + past: If he's here now, he took the early train. (deduction)
  • present continuous: If she's arriving at 6, we should leave now.

This is different from the second conditional, where the past tense means an unreal present: If I had a car… (I don't).

To check if a conditional is real, ask: Is the condition possibly true? If yes, use normal tenses. If it's imaginary, use the unreal patterns. See Second Conditional.

  • If you saw the match last night, you know how good she is. (maybe you saw it)
  • When I was a child, if it snowed, we built snowmen. (past habit)
  • If he didn't come to class yesterday, he won't know about the test. (real past + future)
  • If you're feeling better, you can come with us. (present continuous)

اشتباه‌های رایج:

  • ❌ If you saw the film, you would know the ending. (you may have seen it: a real question) → ✅ If you saw the film, you know the ending. (A real possibility: normal present tense.)
  • ❌ When I was young, if I was bored, I will read. → ✅ When I was young, if I was bored, I read. (Past habit: past in both clauses.)

تمرین سطح B2

13. If you ___ the email I sent yesterday, you already know about the change.
A real past possibility: past simple.
14. When we were kids, if it ___, we played board games.
A past habit: past + past.
15. If she ___ (leave) at 8, she'll be here by now.
A real past possibility: past simple.

C1 · پیشرفته

If you'll wait…: will and should in real if-clauses C1

Will can go after if for willingness, insistence or a later result: If you'll wait here, I'll get the manager. Should after if = less likely.

Normally there's no will in the if clause. But we can use it in some special meanings:

  • Willingness / polite requests: If you'll follow me, I'll show you to your room. (= if you are willing to)
  • Insistence (stressed will): If you will eat so much, of course you feel sick! (= if you insist on)
  • A result that comes later than the main clause: I'll lend you the money if it'll help you. (The help comes after the lending.)

If … should makes a possibility seem less likely or more polite: If you should see Sara, could you give her this? (= if by chance). If … happen to is similar: If you happen to pass a shop, buy some milk.

If … going to talks about a present plan or intention: If you're going to be late, call me.

These patterns are typical of polite or formal English, especially in service situations: If you'd like to take a seat, the doctor will see you soon.

  • If you'll just sign here, we can finish the paperwork. (polite request)
  • I'll take the job if it'll help my career. (result later)
  • If you should have any questions, please contact us. (less likely, formal)
  • If you happen to see my keys, let me know. (by chance)

اشتباه‌های رایج:

  • ❌ If it will rain tomorrow, we'll stay at home. → ✅ If it rains tomorrow, we'll stay at home. (A simple future condition: no will.)
  • ❌ If you should to need help, call me. → ✅ If you should need help, call me. (should + base verb)

تمرین سطح C1

Polite request: If you'll… (= if you are willing to).
17. If you should need anything, just call reception. This means:
If … should = less likely, polite.
18. If you ___ (happen) to see a pharmacy, could you get me some aspirin?
