خانه / گرامر / there is و there are

there is و there areThere Is and There Are

there is (there's) و there are را برای گفتن اینکه چیزی وجود دارد یا جایی هست به کار ببرید، به‌خصوص اولین بار که از آن حرف می‌زنید: There's a café on the corner. There are three people in my family.

برای فرق there is و it is صفحهٔ it مقدماتی را ببینید.

A1 · A2 · B1 · C1

A1 · مبتدی

There's a…, there are some… A1

There is / There's + اسم مفرد یا غیرقابل‌شمارش. There are + اسم جمع: There's a sofa. There's some milk. There are two chairs.

There is (مفرد / غیرقابل‌شمارش)There are (جمع)
There's a book on the table.There are some books on the table.
There's some water in the bottle.There are three bedrooms.
There's a man at the door.There are a lot of people here.

برای این معنی It has نگویید: There's a park near my house (نه It has a park near my house). (در فارسی می‌گوییم «یک پارک دارد»، اما در انگلیسی there is می‌آید.)

  • There's a bank next to the station. مفرد
  • There are two cats in the garden. جمع
  • There's some cheese in the fridge. غیرقابل‌شمارش
  • There are lots of good restaurants here. جمع

اشتباه‌های رایج:

  • ❌ It has a supermarket near my house. → ✅ There's a supermarket near my house. (there is)
  • ❌ There is three bedrooms. → ✅ There are three bedrooms. جمع: there are

There isn't, there aren't any و Is there…? A1

منفی: There isn't a… / There isn't any… (غیرقابل‌شمارش)، There aren't any… (جمع). سؤالی: Is there a…? Are there any…? جواب کوتاه: Yes, there is. No, there aren't.

منفیسؤالیجواب کوتاه
There isn't a bank here.Is there a bank near here?Yes, there is. / No, there isn't.
There isn't any milk.Is there any milk?Yes, there is. / No, there isn't.
There aren't any shops.Are there any shops?Yes, there are. / No, there aren't.

There's no + اسم هم یک شکل دیگرِ منفی است: There's no milk. There are no shops.

  • There isn't a cinema in my town. منفیِ مفرد
  • Are there any good cafés near here? سؤالیِ جمع
  • Is there any coffee? ~ Yes, there is. سؤال + جواب کوتاه
  • There aren't any eggs left. منفیِ جمع

اشتباه‌های رایج:

  • ❌ There aren't some apples. → ✅ There aren't any apples. در منفی: any
  • ❌ Is there any eggs? → ✅ Are there any eggs? جمع: are there
  • ❌ Yes, there's. → ✅ Yes, there is. جواب کوتاه: بدون شکل کوتاه

تمرین سطح A1

1. ___ a cat on the sofa.
مفرد: There's.
2. ___ four people in my family.
جمع: There are.
3. There ___ some milk in the fridge. You can have some now. (one word)
غیرقابل‌شمارش: there is.
4. ___ a pharmacy near here?
سؤالیِ مفرد: Is there…?
5. There ___ any tomatoes. We need to buy some.
منفیِ جمع: aren't any.
6. Are there any chairs in the room? ~ No, there ___. (one word)
جواب کوتاه: No, there aren't.

A2 · مقدماتی

there was, there were, there will be, there has been A2

برای زمان‌های دیگر be را عوض کنید: there was / were (گذشته)، there will be / there's going to be (آینده)، there has / have been (حال کامل).

زمانمفرد / غیرقابل‌شمارشجمع
گذشتهThere was a storm.There were many people.
آیندهThere will be a meeting.There will be two speakers.
going toThere's going to be a party.There are going to be changes.
حال کاملThere has been an accident.There have been problems.

در سؤال، فعل یا فعل کمکی را قبل از there بیاورید: Was there a problem? Will there be food? Has there been any news?

  • There was a lot of traffic this morning. گذشته
  • There were 50 people at the wedding. گذشتهٔ جمع
  • There will be a test next week. آینده
  • There has been an accident on the highway. حال کامل

اشتباه‌های رایج:

  • ❌ There was many people at the concert. → ✅ There were many people at the concert. جمع: were
  • ❌ There will have a party on Saturday. → ✅ There will be a party on Saturday. (there will be)

تمرین سطح A2

7. ___ a lot of people at the party last night.
گذشتهٔ جمع: There were.
8. Don't worry. ___ enough food for everyone.
آینده: There will be.
9. There ___ an accident on the main road. The traffic is terrible. (two words)
حال کامل: has been.

B1 · متوسط

there must be, there seems to be, there used to be B1

there با فعل‌های وجهی و فعل‌های دیگر هم می‌آید: there must / might / could / should be، there seems / appears to be، there used to be، there's bound / likely to be.

الگومثال
there must / might / could beThere must be a mistake.
there should beThere should be more buses at night.
there seems / appears to beThere seems to be a problem.
there used to beThere used to be a cinema here.
there's bound / likely to beThere's bound to be traffic.

در گفتار خودمانی خیلی‌ها there's + اسم جمع می‌گویند: There's two problems. در نوشتن there are بیاورید.

  • There must be a better way. نتیجه‌گیری
  • There seems to be something wrong with my phone. (seems to be)
  • There used to be a park here. وضعیتِ گذشته
  • There might be rain later. احتمال

اشتباه‌های رایج:

  • ❌ There seems a problem. → ✅ There seems to be a problem. (seems to be)
  • ❌ It used to be a cinema here. (it existed) → ✅ There used to be a cinema here. وجود داشتن: there used to be

تمرین سطح B1

10. ___ be some way to fix this. Let's keep trying.
نتیجه‌گیری: There must be.
11. ___ to be a problem with the internet.
There seems to be.
12. There ___ to be a bookshop on this street, but it closed. (one word)
There used to be.

C1 · پیشرفته

There's no point in, there's no need to, for there to be C1

Fixed patterns: There's no point (in) + -ing, There's no need to + verb, There's no way + clause, There's nothing like…, for there to be, and formal there is said / thought to be.

PatternExampleMeaning
There's no point (in) + -ingThere's no point in waiting.it's useless
There's no need to + verbThere's no need to shout.it's not necessary
There's no way + clauseThere's no way I'm paying that much.definitely not (informal)
There's nothing like + noun / -ingThere's nothing like a hot bath.it's the best
for there to beIt's unusual for there to be snow in April.infinitive form
there is said / thought to beThere is said to be gold in the hills.people say

After there's no point (in), use -ing: There's no point complaining (not to complain).

  • There's no point in arguing. He won't change his mind. (no point in)
  • There's no need to book. Just come. (no need to)
  • There's nothing like home-made bread. (nothing like)
  • We don't want there to be any problems. (there to be)

اشتباه‌های رایج:

  • ❌ There's no point to wait any longer. → ✅ There's no point (in) waiting any longer. (no point + -ing)
  • ❌ There's no need that you come. → ✅ There's no need for you to come. (no need for + person + to)

تمرین سطح C1

13. There's no point ___ to him. He never listens.
No point (in) + -ing.
14. There's no ___ to bring food. Lunch is provided.
There's no need to.
15. It's rare ___ there to be so many people here on a Monday. (one word)
For there to be.
