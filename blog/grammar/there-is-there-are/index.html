خانه / گرامر / there is و there are

there is و there areThere Is and There Are

A1 · A2 · B1 · C1

Use there is (there's) and there are to say that something exists or is in a place, especially the first time you mention it: There's a café on the corner. There are three people in my family.

For the difference between there is and it is, see Introductory It.

A1 · مبتدی

There's a…, there are some… A1

There is (singular / uncountable)There are (plural)
There's a book on the table.There are some books on the table.
There's some water in the bottle.There are three bedrooms.
There's a man at the door.There are a lot of people here.

  • There's a bank next to the station. (singular)
  • There are two cats in the garden. (plural)
  • There's some cheese in the fridge. (uncountable)
  • There are lots of good restaurants here. (plural)

اشتباه‌های رایج:

  • ❌ It has a supermarket near my house. → ✅ There's a supermarket near my house. (there is)
  • ❌ There is three bedrooms. → ✅ There are three bedrooms. (plural: there are)

There isn't, there aren't any; Is there…? A1

NegativeQuestionShort answer
There isn't a bank here.Is there a bank near here?Yes, there is. / No, there isn't.
There isn't any milk.Is there any milk?Yes, there is. / No, there isn't.
There aren't any shops.Are there any shops?Yes, there are. / No, there aren't.

  • There isn't a cinema in my town. (negative singular)
  • Are there any good cafés near here? (question plural)
  • Is there any coffee? ~ Yes, there is. (question + short answer)
  • There aren't any eggs left. (negative plural)

اشتباه‌های رایج:

  • ❌ There aren't some apples. → ✅ There aren't any apples. (negative: any)
  • ❌ Is there any eggs? → ✅ Are there any eggs? (plural: are there)
  • ❌ Yes, there's. → ✅ Yes, there is. (short answer: no contraction)

تمرین سطح A1

1. ___ a cat on the sofa.
Singular: There's.
2. ___ four people in my family.
Plural: There are.
3. There ___ some milk in the fridge. You can have some now. (one word)
Uncountable: there is.
4. ___ a pharmacy near here?
Question, singular: Is there…?
5. There ___ any tomatoes. We need to buy some.
Plural negative: aren't any.
6. Are there any chairs in the room? ~ No, there ___. (one word)
Short answer: No, there aren't.

B1 · متوسط

There must be, there seems to be, there used to be B1

PatternExample
there must / might / could beThere must be a mistake.
there should beThere should be more buses at night.
there seems / appears to beThere seems to be a problem.
there used to beThere used to be a cinema here.
there's bound / likely to beThere's bound to be traffic.

  • There must be a better way. (deduction)
  • There seems to be something wrong with my phone. (seems to be)
  • There used to be a park here. (past state)
  • There might be rain later. (possibility)

اشتباه‌های رایج:

  • ❌ There seems a problem. → ✅ There seems to be a problem. (seems to be)
  • ❌ It used to be a cinema here. (it existed) → ✅ There used to be a cinema here. (there used to be)

تمرین سطح B1

10. ___ be some way to fix this. Let's keep trying.
Deduction: There must be.
11. ___ to be a problem with the internet.
There seems to be.
12. There ___ to be a bookshop on this street, but it closed. (one word)
There used to be.

C1 · پیشرفته

There's no point in, there's no need to, for there to be C1

PatternExampleMeaning
There's no point (in) + -ingThere's no point in waiting.it's useless
There's no need to + verbThere's no need to shout.it's not necessary
There's no way + clauseThere's no way I'm paying that much.definitely not (informal)
There's nothing like + noun / -ingThere's nothing like a hot bath.it's the best
for there to beIt's unusual for there to be snow in April.infinitive form
there is said / thought to beThere is said to be gold in the hills.people say

  • There's no point in arguing. He won't change his mind. (no point in)
  • There's no need to book. Just come. (no need to)
  • There's nothing like home-made bread. (nothing like)
  • We don't want there to be any problems. (there to be)

اشتباه‌های رایج:

  • ❌ There's no point to wait any longer. → ✅ There's no point (in) waiting any longer. (no point + -ing)
  • ❌ There's no need that you come. → ✅ There's no need for you to come. (no need for + person + to)

تمرین سطح C1

13. There's no point ___ to him. He never listens.
No point (in) + -ing.
14. There's no ___ to bring food. Lunch is provided.
There's no need to.
15. It's rare ___ there to be so many people here on a Monday. (one word)
For there to be.
