خانه / گرامر / some و any

some و anySome and Any

Some and any talk about an amount that isn't exact. Use them with plural nouns (some eggs) and uncountable nouns (some milk).

The basic rule is some in positive sentences and any in negatives and questions, but there are important exceptions. For countable and uncountable nouns, see Countable and Uncountable Nouns.

A1 · A2 · B1 · B2

A1 · مبتدی

Some in positive sentences, any in negatives and questions A1

Use some in positive sentences (I've got some apples). Use any in negatives (I haven't got any apples) and most questions (Have you got any apples?).

Plural nounUncountable noun
positiveThere are some eggs.There's some milk.
negativeThere aren't any eggs.There isn't any milk.
questionAre there any eggs?Is there any milk?

Use some / any with plural and uncountable nouns. With a singular countable noun, use a / an: Is there a bank near here? (not any bank)

  • I bought some bread. (positive)
  • We don't have any homework today. (negative)
  • Are there any good restaurants near here? (question)
  • There's some juice in the fridge. (uncountable)

اشتباه‌های رایج:

  • ❌ I don't have some money. → ✅ I don't have any money. (negative: any)
  • ❌ There are any chairs in the room. → ✅ There are some chairs in the room. (positive: some)
  • ❌ Have you got any pen? → ✅ Have you got a pen? (singular countable: a)

تمرین سطح A1

1. There's ___ milk in the fridge.
Positive + uncountable: some.
2. I don't have ___ brothers or sisters.
Negative: any.
3. There aren't ___ eggs left. Can you buy some? (one word)
Negative: any.

A2 · مقدماتی

Some in offers and requests: Can I have some water? A2

Use some in questions when you offer something or ask for something, or when you expect the answer yes: Would you like some coffee? Can I have some water?

Question typeExample
offersWould you like some cake?
requestsCan I have some water, please? Could you lend me some money?
expecting yesDid you buy some bread? (I think you did.)
real questionsIs there any bread? (I don't know.)

Compare: Have you got any questions? (an open question) / Would you like some more tea? (an offer).

  • Would you like some biscuits? (offer)
  • Can I have some more rice, please? (request)
  • Could you give me some advice? (request)
  • Are there any messages for me? (real question)

اشتباه‌های رایج:

  • ❌ Can I have any water, please? → ✅ Can I have some water, please? (request: some)

Someone, anything, nowhere, everybody A2

Some-, any-, no-, every- combine with -one / -body (people), -thing (things) and -where (places): someone, anything, nowhere, everybody. Use them like some and any.

some-any-no-every-
peoplesomeone / somebodyanyone / anybodyno one / nobodyeveryone / everybody
thingssomethinganythingnothingeverything
placessomewhereanywherenowhereeverywhere

No- words already have a negative meaning, so use a positive verb: I saw nobody. = I didn't see anybody. (not I didn't see nobody)

These words take a singular verb: Everyone is here. Nothing has changed.

Don't use to before somewhere / anywhere after go: Let's go somewhere quiet.

  • Someone is knocking at the door. (some-)
  • I didn't buy anything. (negative: any-)
  • There's nowhere to park. (no-)
  • Everybody loves her. (every-)

اشتباه‌های رایج:

  • ❌ I didn't say nothing. → ✅ I didn't say anything. (one negative only)
  • ❌ Everyone are happy. → ✅ Everyone is happy. (singular verb)
  • ❌ I want to go to somewhere warm. → ✅ I want to go somewhere warm. (no to before somewhere)

تمرین سطح A2

4. Can I have ___ water, please? I'm really thirsty.
Request: some.
5. Which question is an offer?
Offers: Would you like some…?
6. Could you lend me ___ money? I left my wallet at home. (one word)
Request: some.
7. Is there ___ in the bathroom? The door is locked.
Question about a person: anyone.
8. I'm bored. There's ___ to do here.
No-word with a positive verb: There's nothing.
9. I can't find my keys ___. I've looked in every room. (one word ending in -where)
Negative + place: anywhere.

B1 · متوسط

Any = it doesn't matter which; any after if B1

In positive sentences, any means it doesn't matter which: Call me any time. Use any after if and with words that have a negative meaning (never, hardly, without).

UseExample
it doesn't matter whichChoose any colour you like. Anyone can learn to cook.
ifIf you have any questions, call me.
negative meaningHe never has any money. She left without saying anything.
hardly anyThere's hardly any milk left. (= almost none)

With this meaning, any can go with a singular noun: Any child can do it. Take any bus from here.

Not… any = no: There aren't any chairs. = There are no chairs. Use only one negative.

  • You can sit anywhere. (doesn't matter where)
  • Any bus from this stop goes to the centre. (doesn't matter which)
  • If you need anything, just ask. (if)
  • There were hardly any people at the party. (hardly any)

اشتباه‌های رایج:

  • ❌ You can come some time you like. → ✅ You can come any time you like. (doesn't matter when: any)
  • ❌ There is hardly some food. → ✅ There is hardly any food. (hardly + any)
  • ❌ I don't have no time. → ✅ I don't have any time. (one negative only)

تمرین سطح B1

10. Call me ___ time. I'm always at home.
It doesn't matter when: any time.
11. If you have ___ problems, let me know.
After if: any.
12. There's hardly ___ petrol left. We need to stop. (one word)
Hardly any = almost none.

B2 · بالاتر از متوسط

Some 200 people, some idiot, any better, no faster B2

Some + number = about (some 200 people). Some + singular noun = an unknown person or thing (Some idiot parked in my space). Any / no + comparative = at all (Is he any better? It's no faster.).

UseExample
some + number = about (formal)Some 300 people attended the conference.
some + singular noun = unknownShe married some guy she met online.
stressed some = certain, not allSOME people think it's a good idea. (but not everyone)
any + comparativeAre you feeling any better? It isn't any easier.
no + comparativeThe new phone is no faster than the old one.

Use no or none, not not any, at the start of a sentence: No students passed. None of my friends came. (not Not any students passed)

Any + comparative is common in questions and negatives: Can't you drive any faster?

  • Some 50,000 fans watched the match. (about)
  • Some man called, but he didn't leave his name. (unknown person)
  • Is your cold any better today? (any + comparative)
  • No one knows the answer. (no at the start)

اشتباه‌های رایج:

  • ❌ Not any of the students passed. → ✅ None of the students passed. (at the start: none)
  • ❌ The traffic isn't no better today. → ✅ The traffic isn't any better today. (not + any)

تمرین سطح B2

13. ___ 5,000 people took part in the march.
About: some + number.
14. Is the traffic ___ better today?
Any + comparative in questions.
15. ___ students passed the exam. It was far too difficult. (one word)
At the start: No students…
