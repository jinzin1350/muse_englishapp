some و anySome and Any

some و any دربارهٔ مقداری حرف می‌زنند که دقیق نیست (معمولاً «مقداری، چند تا»). آن‌ها را با اسم‌های جمع (some eggs) و غیرقابل‌شمارش (some milk) بیاورید.

قاعدهٔ اصلی این است: some در جملهٔ مثبت و any در جملهٔ منفی و سؤالی؛ اما چند استثنای مهم دارد. برای اسم‌های قابل‌شمارش و غیرقابل‌شمارش صفحهٔ اسم‌های قابل‌شمارش و غیرقابل‌شمارش را ببینید.

A1 · A2 · B1 · B2

A1 · مبتدی

some در جملهٔ مثبت، any در منفی و سؤالی A1

در جملهٔ مثبت some بیاورید (I've got some apples). در جملهٔ منفی (I haven't got any apples) و بیشتر سؤال‌ها (Have you got any apples?) any بیاورید.

اسم جمعاسم غیرقابل‌شمارش
مثبتThere are some eggs.There's some milk.
منفیThere aren't any eggs.There isn't any milk.
سؤالیAre there any eggs?Is there any milk?

some / any را با اسم جمع و غیرقابل‌شمارش بیاورید. با اسم مفردِ قابل‌شمارش a / an بیاورید: Is there a bank near here? (نه any bank)

  • I bought some bread. مثبت
  • We don't have any homework today. منفی
  • Are there any good restaurants near here? سؤالی
  • There's some juice in the fridge. غیرقابل‌شمارش

اشتباه‌های رایج:

  • ❌ I don't have some money. → ✅ I don't have any money. در جملهٔ منفی any می‌آید.
  • ❌ There are any chairs in the room. → ✅ There are some chairs in the room. در جملهٔ مثبت some می‌آید.
  • ❌ Have you got any pen? → ✅ Have you got a pen? اسم مفردِ قابل‌شمارش: a.

تمرین سطح A1

1. There's ___ milk in the fridge.
مثبت + غیرقابل‌شمارش: some.
2. I don't have ___ brothers or sisters.
منفی: any.
3. There aren't ___ eggs left. Can you buy some? (one word)
منفی: any.

A2 · مقدماتی

some در تعارف و درخواست: Can I have some water? A2

وقتی چیزی تعارف می‌کنید یا چیزی درخواست می‌کنید، یا انتظار دارید جواب yes باشد، در سؤال هم some بیاورید: Would you like some coffee? Can I have some water?

نوع سؤالمثال
تعارفWould you like some cake?
درخواستCan I have some water, please? Could you lend me some money?
وقتی انتظار yes داریدDid you buy some bread? (فکر می‌کنم خریده‌ای.)
سؤال واقعیIs there any bread? (نمی‌دانم.)

مقایسه کنید: Have you got any questions? (یک سؤال باز) / Would you like some more tea? (تعارف).

  • Would you like some biscuits? تعارف
  • Can I have some more rice, please? درخواست
  • Could you give me some advice? درخواست
  • Are there any messages for me? سؤال واقعی

اشتباه‌های رایج:

  • ❌ Can I have any water, please? → ✅ Can I have some water, please? درخواست: some.

someone, anything, nowhere, everybody A2

some-, any-, no-, every- با ‑one / ‑body (برای آدم‌ها)، ‑thing (برای چیزها) و ‑where (برای جاها) ترکیب می‌شوند: someone, anything, nowhere, everybody. این‌ها را مثل some و any به کار ببرید.

some-any-no-every-
آدم‌هاsomeone / somebodyanyone / anybodyno one / nobodyeveryone / everybody
چیزهاsomethinganythingnothingeverything
جاهاsomewhereanywherenowhereeverywhere

کلمه‌های no- خودشان معنی منفی دارند، پس فعل مثبت بیاورید: I saw nobody. = I didn't see anybody. (نه I didn't see nobody). در فارسی می‌گوییم «هیچ‌کس را ندیدم» و دو منفی داریم، اما در انگلیسی فقط یک منفی می‌آید.

این کلمه‌ها فعل مفرد می‌گیرند: Everyone is here. Nothing has changed.

بعد از go قبل از somewhere / anywhere حرف to نیاورید: Let's go somewhere quiet.

  • Someone is knocking at the door. some-
  • I didn't buy anything. منفی: any-
  • There's nowhere to park. no-
  • Everybody loves her. every-

اشتباه‌های رایج:

  • ❌ I didn't say nothing. → ✅ I didn't say anything. فقط یک منفی.
  • ❌ Everyone are happy. → ✅ Everyone is happy. فعل مفرد.
  • ❌ I want to go to somewhere warm. → ✅ I want to go somewhere warm. قبل از somewhere حرف to نمی‌آید.

تمرین سطح A2

4. Can I have ___ water, please? I'm really thirsty.
درخواست: some.
5. کدام سؤال تعارف است؟
تعارف: Would you like some…?
6. Could you lend me ___ money? I left my wallet at home. (one word)
درخواست: some.
7. Is there ___ in the bathroom? The door is locked.
سؤال دربارهٔ یک آدم: anyone.
8. I'm bored. There's ___ to do here.
کلمهٔ no- با فعل مثبت: There's nothing.
9. I can't find my keys ___. I've looked in every room. (one word ending in -where)
منفی + جا: anywhere.

B1 · متوسط

any یعنی «هر کدام، فرقی نمی‌کند»؛ any بعد از if B1

در جملهٔ مثبت، any یعنی هر کدام، فرقی نمی‌کند کدام: Call me any time. بعد از if و با کلمه‌هایی که معنی منفی دارند (never, hardly, without) هم any بیاورید.

کاربردمثال
فرقی نمی‌کند کدامChoose any colour you like. Anyone can learn to cook.
ifIf you have any questions, call me.
معنی منفیHe never has any money. She left without saying anything.
hardly anyThere's hardly any milk left. (یعنی تقریباً هیچ)

با این معنی، any می‌تواند با اسم مفرد بیاید: Any child can do it. Take any bus from here.

Not… any یعنی no: There aren't any chairs. = There are no chairs. فقط یک منفی بیاورید.

  • You can sit anywhere. فرقی نمی‌کند کجا
  • Any bus from this stop goes to the centre. فرقی نمی‌کند کدام
  • If you need anything, just ask. if
  • There were hardly any people at the party. hardly any (تقریباً هیچ)

اشتباه‌های رایج:

  • ❌ You can come some time you like. → ✅ You can come any time you like. فرقی نمی‌کند کی: any.
  • ❌ There is hardly some food. → ✅ There is hardly any food. hardly + any.
  • ❌ I don't have no time. → ✅ I don't have any time. فقط یک منفی.

تمرین سطح B1

10. Call me ___ time. I'm always at home.
فرقی نمی‌کند کی: any time.
11. If you have ___ problems, let me know.
بعد از if: any.
12. There's hardly ___ petrol left. We need to stop. (one word)
Hardly any یعنی تقریباً هیچ.

B2 · بالاتر از متوسط

Some 200 people, some idiot, any better, no faster B2

Some + number = about (some 200 people). Some + singular noun = an unknown person or thing (Some idiot parked in my space). Any / no + comparative = at all (Is he any better? It's no faster.).

UseExample
some + number = about (formal)Some 300 people attended the conference.
some + singular noun = unknownShe married some guy she met online.
stressed some = certain, not allSOME people think it's a good idea. (but not everyone)
any + comparativeAre you feeling any better? It isn't any easier.
no + comparativeThe new phone is no faster than the old one.

Use no or none, not not any, at the start of a sentence: No students passed. None of my friends came. (not Not any students passed)

Any + comparative is common in questions and negatives: Can't you drive any faster?

  • Some 50,000 fans watched the match. (about)
  • Some man called, but he didn't leave his name. (unknown person)
  • Is your cold any better today? (any + comparative)
  • No one knows the answer. (no at the start)

اشتباه‌های رایج:

  • ❌ Not any of the students passed. → ✅ None of the students passed. (at the start: none)
  • ❌ The traffic isn't no better today. → ✅ The traffic isn't any better today. (not + any)

تمرین سطح B2

13. ___ 5,000 people took part in the march.
About: some + number.
14. Is the traffic ___ better today?
Any + comparative in questions.
15. ___ students passed the exam. It was far too difficult. (one word)
At the start: No students…
