Used To, Would, Be Used To and Get Used To

Level: B2 · Free grammar guide

These four forms look similar but mean different things:

used to + verb = a past habit or state (I used to live in Rome), would + verb = a repeated past action (We would play outside every day), be used to + -ing = something is normal for you (I'm used to getting up early), get used to + -ing = something becomes normal for you (I'm getting used to living alone).

Comparison

FormMeaningExample
used to + verbpast habit or state, not true nowI used to smoke, but I stopped.
would + verbrepeated past action (not states)Every summer, we would go to the lake.
be used to + -ing / nounit's normal, not strange or difficultShe's used to working at night.
get used to + -ing / nounit becomes normal (a process)You'll soon get used to the cold.

Used to and would

For repeated actions in the past, you can use used to or would: When I was a child, my grandmother used to / would tell me stories.

For past states (be, have, live, like, know), use only used to: I used to have long hair (not I would have long hair).

Questions and negatives: Did you use to play football? I didn't use to like vegetables. (no -d after did)

Be used to and get used to

Here, to is a preposition, so it's followed by a noun or -ing, not the base verb: I'm used to driving on the right (not used to drive).

Get used to can be in any tense: It took me months to get used to it. I'm getting used to it. I'll never get used to it. I've got used to it.

Examples

  1. We used to live in a village, but now we live in the city. (past state)
  2. My dad would make pancakes every Sunday. (repeated past action)
  3. I'm a nurse, so I'm used to working nights. (it's normal for me)
  4. Are you used to the noise yet? (be used to + noun)
  5. It took me a year to get used to the Canadian winter. (process)
  6. I'm slowly getting used to my new glasses. (process, continuous)
  7. I'm not used to eating so late. (negative)
  8. Did you use to play an instrument? (question)
  9. She didn't use to like coffee, but now she loves it. (negative)
  10. You'll get used to speaking English every day. (future)

Common mistakes

❌ I'm used to get up early.

✅ I'm used to getting up early. (Be used to + -ing.)

❌ I would have a dog when I was young.

✅ I used to have a dog when I was young. (Would isn't used for past states.)

❌ I can't get used to live here.

✅ I can't get used to living here. (Get used to + -ing.)

❌ Did you used to play tennis?

✅ Did you use to play tennis? (After did, use use to (no -d).)

❌ I used to working from home now.

✅ I'm used to working from home now. (For what is normal now, use be used to.)

❌ She is used to live alone.

✅ She is used to living alone. (Be used to + -ing.)
