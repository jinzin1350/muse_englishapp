Be Used To and Get Used To

B1 · B2 · C1

Be used to something means it's familiar, so it isn't strange or difficult any more: I've lived in Canada for years, so I'm used to the cold. Get used to means it's becoming familiar: I'm getting used to my new job.

Don't confuse them with used to + base verb, which talks about past habits: I used to live in Tehran. See Used To.

B1 · Intermediate

Used to do or be used to doing? B1

FormMeaningExample
used to + base verbpast habit or state, not nowI used to live in a village. (I don't now.)
be used to + -ing / nounfamiliar, not strangeI'm used to living in a big city. (It's normal for me.)

  • I used to play football every day. (past habit)
  • I'm used to working at night. (familiar)
  • She used to be shy, but now she's very confident. (past state)
  • He isn't used to the hot weather. (not familiar)

Common mistakes:

  • ❌ I'm used to get up early. → ✅ I'm used to getting up early. (be used to + -ing)
  • ❌ I used to living in Paris. (a past habit) → ✅ I used to live in Paris. (used to + base verb)

B2 · Upper-intermediate

Be used to: in all tenses B2

  • At first, I wasn't used to the time difference. (past)
  • Are you used to your new glasses? (question)
  • My kids are used to going to bed at eight. (present)
  • You'll be used to it in a few weeks. (future)

Common mistakes:

  • ❌ I'm not used to speak English all day. → ✅ I'm not used to speaking English all day. (+ -ing)
  • ❌ Do you used to the cold? → ✅ Are you used to the cold? (be used to: question with be)

Get used to: becoming familiar B2

  • I'm slowly getting used to my new glasses. (in progress)
  • It took me a year to get used to the weather. (process in the past)
  • Don't worry, you'll get used to it. (future)
  • I can't get used to eating dinner so late. (still strange)

Common mistakes:

  • ❌ I'm getting used to wake up early. → ✅ I'm getting used to waking up early. (+ -ing)
  • ❌ I can't get use to this weather. → ✅ I can't get used to this weather. (used, with -d)

C1 · Advanced

Accustomed to, grow used to, and passive -ing after used to C1

  • The villagers are accustomed to long winters. (formal)
  • Over time, he grew used to the silence. (slow change)
  • She isn't used to being criticised. (passive -ing)
  • Visitors soon become accustomed to the altitude. (formal process)

Common mistakes:

  • ❌ I'm not used to be treated like this. → ✅ I'm not used to being treated like this. (passive -ing: being + pp)
  • ❌ She is accustomed to work late. (less common) → ✅ She is accustomed to working late. (accustomed to + -ing (more common))
