خانه / گرامر / be used to و get used to

be used to و get used toBe Used To and Get Used To

be used to چیزی یعنی آن چیز برایتان عادی است و دیگر عجیب یا سخت نیست (به آن عادت دارید): I've lived in Canada for years, so I'm used to the cold. get used to یعنی دارد برایتان عادی می‌شود (دارید عادت می‌کنید): I'm getting used to my new job.

این‌ها را با used to + شکل سادهٔ فعل قاطی نکنید که دربارهٔ عادت‌های گذشته است: I used to live in Tehran. صفحهٔ used to را ببینید.

B1 · B2 · C1

B1 · متوسط

used to do یا be used to doing؟ B1

used to + شکل سادهٔ فعل یعنی عادتی در گذشته (الان نه). be used to + ‑ing / اسم یعنی برایم عادی است، به آن عادت دارم.

ساختارمعنیمثال
used to + شکل سادهٔ فعلعادت یا حالتی در گذشته، الان نهI used to live in a village. (الان نه.)
be used to + ‑ing / اسمآشنا و عادی، نه عجیبI'm used to living in a big city. (برایم عادی است.)

در be used to، to حرف اضافه است، پس بعدش اسم یا ‑ing می‌آید: I'm used to the noise. I'm used to getting up early.

فرق در فعل be است: I used to drive (عادت گذشته) / I'm used to driving (به آن عادت دارم).

  • I used to play football every day. عادت گذشته
  • I'm used to working at night. عادت دارم
  • She used to be shy, but now she's very confident. حالت گذشته
  • He isn't used to the hot weather. عادت ندارد

اشتباه‌های رایج:

  • ❌ I'm used to get up early. → ✅ I'm used to getting up early. be used to + ‑ing.
  • ❌ I used to living in Paris. (a past habit) → ✅ I used to live in Paris. used to + شکل سادهٔ فعل (عادت گذشته).

تمرین سطح B1

1. When I was a child, I ___ climb trees.
عادت گذشته: used to + شکل سادهٔ فعل.
2. I've worked nights for years, so I ___ sleeping during the day.
عادی شده: be used to + ‑ing.
3. She's from Finland, so she's used to ___ (be) in the cold.
Be used to + ‑ing.

B2 · بالاتر از متوسط

Be used to: in all tenses B2

be used to works in any tense: I'm used to it. I wasn't used to it. I've never been used to it. You'll be used to it soon.

Change be to show the time: When I arrived, I wasn't used to the food. I've been used to early starts since I was a child.

Negative: not used to: I'm not used to such cold weather. Question: Are you used to the noise?

After be used to, use a noun, a pronoun or -ing: She's used to it. She's used to big cities. She's used to travelling.

  • At first, I wasn't used to the time difference. (past)
  • Are you used to your new glasses? (question)
  • My kids are used to going to bed at eight. (present)
  • You'll be used to it in a few weeks. (future)

اشتباه‌های رایج:

  • ❌ I'm not used to speak English all day. → ✅ I'm not used to speaking English all day. (+ -ing)
  • ❌ Do you used to the cold? → ✅ Are you used to the cold? (be used to: question with be)

Get used to: becoming familiar B2

get used to + -ing / noun = the process of becoming familiar: I'm getting used to my new job. It took me months to get used to the cold.

Get used to describes a change: something strange becomes normal. It's often used with can't, it took, I'll, I'm getting: I can't get used to driving on the right. You'll get used to it.

Compare: I'm used to the cold (a state: it's normal now) / I'm getting used to the cold (a process: it's becoming normal).

  • I'm slowly getting used to my new glasses. (in progress)
  • It took me a year to get used to the weather. (process in the past)
  • Don't worry, you'll get used to it. (future)
  • I can't get used to eating dinner so late. (still strange)

اشتباه‌های رایج:

  • ❌ I'm getting used to wake up early. → ✅ I'm getting used to waking up early. (+ -ing)
  • ❌ I can't get use to this weather. → ✅ I can't get used to this weather. (used, with -d)

تمرین سطح B2

C1 · پیشرفته

Accustomed to, grow used to, and passive -ing after used to C1

Formal alternatives: be / become accustomed to + -ing / noun. Gradual change: grow used to. Passive: be used to being + past participle (I'm not used to being ignored).

Be accustomed to means the same as be used to but is more formal: The staff are accustomed to dealing with difficult customers. Become / grow accustomed to = get used to.

Grow used to stresses a slow change: Over the years, she grew used to living alone.

For things that happen to you, use the passive -ing: He's used to being told what to do. I'm not used to being treated like this.

In formal English, accustomed to + infinitive also exists (accustomed to do), but accustomed to + -ing is more common today.

  • The villagers are accustomed to long winters. (formal)
  • Over time, he grew used to the silence. (slow change)
  • She isn't used to being criticised. (passive -ing)
  • Visitors soon become accustomed to the altitude. (formal process)

اشتباه‌های رایج:

  • ❌ I'm not used to be treated like this. → ✅ I'm not used to being treated like this. (passive -ing: being + pp)
  • ❌ She is accustomed to work late. (less common) → ✅ She is accustomed to working late. (accustomed to + -ing (more common))

تمرین سطح C1
